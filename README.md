# 津波防災もしも再現（tsunami-bousai-moshimo-saigen）

地図で地点を選ぶと、その街の実際の地形と建物の上に、仮定の津波が「水」として押し寄せます。建物にぶつかり、道や運河を流れ、盛土で止まる様子を、非線形浅水方程式でGPU計算して見せるサイトです。**予測ではありません。**

最初に見せる地域は名古屋です（名古屋港・海抜ゼロメートル地帯のプリセットあり）。

- 公開ページ：https://share.akirafunakoshi.com/tsunami-simulation/
- リポジトリ：https://github.com/Akira-Papa/tsunami-bousai-moshimo-saigen（開発時の作業名は「津波シティ」／tsunami-city-webgpu）

## 起動
```bash
npm install
npm run dev   # http://127.0.0.1:5341
```
- WebGPU 対応ブラウザが必要です（Chrome / Edge 113 以降、Safari 26 以降）
- `?demo=1` を付けると、通信なしの合成の港町で動きます
- `?lat=35.0905&lon=136.8844&auto=1&n=768&h=5&tide=1.2&levee=1&crest=4.6&breach=1` のように、地点・格子・海の高さ・潮位・防潮壁を指定して自動で開始できます
- ソルバーの検証は `/test.html` で行います（静止湖・ダム崩壊・海浜の水位上げ）

## しくみ

| 層 | 内容 |
|---|---|
| 地形 | 国土地理院 `dem5a_png`（5m）＋`dem_png`（10m）。無効値は海・水面として扱い、合成の水深（d = 3 + s/8、最大14m）を与える |
| 建物 | PLATEAU LOD1（実測の高さ）を優先し、なければ国土地理院ベクトルタイルの建物（種別から高さを推定）。格子に反射壁としてラスタ化 |
| 航空写真 | 国土地理院 `seamlessphoto`（z16〜17）を地面と屋根に使う |
| 津波の高さ | 内閣府（2025）南海トラフ巨大地震の、市区町村別の海岸最大津波高。一覧にない区は、同じ市の区または近くの市町村の値で代用し、画面にそう表示する |
| 公式との比較 | 内閣府2025 ケース01 の浸水メッシュを100mに集約した値（最大浸水深・最早到達）。斜線で重ね描きし、結果画面で並べる |
| 物理 | MUSCL（η）-minmod ＋ Audusse の静水圧再構成 ＋ HLL ＋ SSP-RK2。Manning摩擦（半陰的）、速度の脱特異化。1段を1つのTSL computeで計算し、2バッファで回す |
| 潮位・防潮壁 | 初期潮位（名古屋港 T.P.+1.2m、愛知県の他地域 +1.0m、いずれも一次情報）。防潮壁は地理院の「堤防等に接する」海岸線・河岸、水門（閉鎖）の位置に置き、名古屋港は天端 T.P.+4.6m。越流したら壊れる（公式想定と同じ条件） |
| 内陸の地点 | 海から遠い地点（名古屋駅など）は二段のネスト計算。広域（最大20km四方・約14m格子、市街地は粗度で表す）が海から街への広がりを計算し、地点の周り1.5km四方（約2m・建物は壁）が縁から広域の水位と流速を受け取る |
| 造波 | 沖の開けた海に幅200mの帯を置き、リーマン不変量で長波を入れる（反射波は外へ抜ける）。岸近くの平均水位が「海の高さ」になるよう、入力振幅をフィードバックで調整 |
| 縁 | 造波帯では流出のみを許す。それ以外の縁は鏡像壁 |
| 付随場 | 泡（ボア前面・壁への衝突・射流・水の先端）、濁り（陸での巻き上げ）、濡れ、最大浸水深、到達時刻。すべて半ラグランジュ法で移流 |
| 描画 | 解析的な屈折で水底（航空写真）を描き、濁りに応じて吸収・散乱。フレネル・空の反射・建物の映り込み・焼き込んだ日影。面積比法のコースティクスと近景の光の網。泡のレース模様、飛沫粒子（2^17個、GPU） |
| わかりやすさ | 地点に1m目盛りの柱と170cmの人影、2階の床の線、「海の高さ＝地面から○m」の帯。HUDに今の深さ・最大・流速・水の先端までの距離・公式値・標高。結果画面で公式と同じ物差しの比較 |

## 画面と用語（日向の決定）
- 呼び名は「もしも再現」で統一し、「予測」「安全」とは書かない
- **海の高さ**は海岸での津波の高さ（標高基準）、**ここの深さ**は選んだ地点の地面からの浸水深
- 時計は「押し波の開始から」の時間。公式の到達時刻は「地震から」の時間なので、基準が違うことを画面に明記

## 限界（必ず読むこと）
- 防潮壁は岸の線（地理院の「堤防等に接する」線）で近似している。実際のラインが岸壁より内陸側にある区間は再現しない。沖の高潮防波堤は含まない
- 名古屋港以外は、防潮壁の高さと満潮位を確認できていない（既定は防潮壁OFF・潮位0m）
- 海底の地形は合成（海岸からの距離で決めた水深）
- 建物の破壊・漂流物・地盤沈下は含まない
- 1段計算は最大4km四方。それより海から遠い地点はネスト計算（広域は最大20km四方）。広域では建物を壁として扱わず、粗度で表す
