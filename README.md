# 津波防災もしも再現（tsunami-bousai-moshimo-saigen）

家や学校の近くを地図で選ぶと、まず **その場所に来る水の深さ（国の想定）**、**津波から逃げる場所（指定緊急避難場所）**、**そこまでの道のり** が出ます（どの端末でも）。さらに、その街の実際の地形と建物の上に、仮定の津波が「水」として押し寄せる様子を、非線形浅水方程式でGPU計算して3Dで見せます（WebGPU 対応ブラウザ）。建物にぶつかり、道や運河を流れ、盛土で止まります。上から見たり、その場所に立って見たりできます。**予測ではありません。**

> **強い揺れや、弱くても長い揺れを感じたら、すぐ高い所へ避難を。**

日本中のどの地点でも使えます（公式想定の表示は内閣府2025の収録範囲）。建物の公式データ（PLATEAU）を最も詳しく入れているのは名古屋です（名古屋港・海抜ゼロメートル地帯のプリセットあり）。

使い方は3つの段階です。

1. **場所をえらぶ**：住所をさがすか、地図をおす
2. **深さと逃げる場所を見る**：ここに来る水の深さ、水が来はじめる時間（地震から最も早くて）、逃げる場所と道のり
3. **3Dで見る**：津波の高さ（海岸での海の高さ・仮定）を決めて、水が来る様子を見る

### 2026-11 のアップデート（Fable 5.2）

- **いまやることを一番上に**：場所を選ぶと、まず「ここに来る水の深さ」を大きな数字と絵で1つだけ出し、続けて「待ってよい時間ではありません」と添えた到達の目安を出す。誤った安心につながる言い方をなくした
- **津波の高さをカードの一番上で選べる**：− ／ ＋ のボタンとスライダー。3Dと「高い所への道」に効き、国の想定の深さは変わらないことを画面に書いた
- **逃げる道のり（目安）**：選んだ地点から、指定緊急避難場所（近い順に3か所）と、標高が津波の高さを超える「高い所」までの道を、国土地理院の道路中心線で求めて地図に出す。3Dの地面にも帯で描く（緑＝指定の逃げる場所まで、橙＝高い所まで、灰色の点線＝いま水の下）
- **WebGPU がない端末でも**、公式の想定と逃げる場所と道のりは使える
- **水の流れが見える**：流れの向きと速さの印、水のふちの線、濁流としての見た目
- **計算は毎回同じ結果に**：同じ条件なら、再生の速さや端末の速さによらず同じ数字になる。裏のタブや遅い端末でも、再現の時計が実時間どおりに進む
- **3Dの画面を組み直し**：3Dが見える面積を広げ、操作を2行にまとめ、押す所はすべて44px以上。上から見る・地点の近くへ寄る・その場所に立って見回す、がしやすい
- **消える家の意味**：流された木造の家だと分かるように表示
- **画面全体を作り直し**：明るい地に濃い字、本文16px以上、大きなボタン、短い言葉。お年寄りにも子どもにも読めることを目標にした

## 起動
```bash
npm install
npm run dev   # http://127.0.0.1:5341
```
- 3D の再現には WebGPU 対応ブラウザが必要です（Chrome / Edge 113 以降、Safari 26 以降）。WebGPU がない端末でも、地点の選択・公式想定・逃げる場所・避難メモは使えます（地図も出せない端末では文字だけで出ます）
- 共有リンクは地点と条件だけ（`?lat=…&lon=…&h=…&tide=…&levee=…&crest=…&breach=…`）。結果の数字は入りません
- `?demo=1` を付けると、通信なしの合成の港町で動きます
- `?lat=35.0905&lon=136.8844&auto=1&n=768&h=5&tide=1.2&levee=1&crest=4.6&breach=1` のように、地点・格子・海の高さ・潮位・防潮壁を指定して自動で開始できます
- ソルバーの検証は `/test.html` で行います（静止湖・ダム崩壊・海浜の水位上げ）

## 画面と用語（日向の決定）
- 呼び名は「もしも再現」で統一し、「予測」「安全」とは書かない
- **海の高さ**は海岸での津波の高さ（標高基準）、**ここの深さ**は選んだ地点の地面からの浸水深
- 時計は「再現の時計」（計算の始まりから）。再現の到達時刻は出さない（人工の海底と計算範囲で決まる値で、猶予時間に読まれるため）。時刻として出すのは公式の「地震から最も早くて約○分」だけで、「猶予の時間ではありません」を添える
- 水が届かなかったときは「計算した約○分の間は届かず。安全という意味ではありません」と書き、公式想定を同じ枠に並べる（「到達せず」「浸水なし」を単独で出さない）
- 深さの目安は一次情報どおり：内閣府の被害想定の手法（浸水深30cm以上で死者が発生し始め、1mでは津波に巻き込まれた人のすべてが亡くなると仮定）、気象庁（20〜30cmでも速い流れに巻き込まれるおそれ。木造家屋は2mで全面破壊に至る目安）

## 限界（必ず読むこと）
- 防潮壁は岸の線（地理院の「堤防等に接する」線）で近似している。実際のラインが岸壁より内陸側にある区間は再現しない。沖の高潮防波堤は含まない
- 名古屋港以外は、防潮壁の高さと満潮位を確認できていない（既定は防潮壁OFF・潮位0m）
- 海底の地形は合成（海岸からの距離で決めた水深）
- 建物の破壊は木造（推定）の流失のみ。漂流物・地盤沈下は含まない
- 入力は1つの波（一様な長波）で、計算する時間は1段計算で約40分、内陸のネスト計算で約90分。実際の津波は長い時間くり返し来る
- 公式想定の表示はケース01だけ（11ケースの1つ）。ほかのケース・都道府県や市町村の想定は、自治体のハザードマップで確かめること
- 逃げる道のりは国土地理院の道路中心線から求めた目安。通れるとは限らない（橋・線路・階段・工事・夜間の施錠・がれきは分からない）。逃げるのは、水が来る前
- 逃げる場所の一覧の距離は直線
- 名古屋の PLATEAU データには建物ごとの津波浸水想定がないため、建物ごとの比較は内閣府の100m集約値を建物の中心で引いたもの
- 1段計算は最大4km四方。それより海から遠い地点はネスト計算（広域は最大20km四方）。広域では建物を壁として扱わず、粗度で表す
