## 3. A　水の流れ

### いま、なぜ伝わらないか（オルテガの実測）

1. **時間のものさしが2つある。** 水そのものは ×20 で進むのに、水面の模様は実時間で動く。先端は画面の上で秒速60m相当、模様は秒速3m。
2. **向きの印がない。** いまの筋は、流れが右向きでも左向きでも同じ絵になる。押し波と引き波の区別がつかない。
3. **防潮壁を越えるまで、何も起きない。** 海面の上がり方は1秒に約1cm。×20 でも約35秒、変化が見えない。
4. **先端が読めない。** 先端のセルは、描画へ渡すときに流れを0にしている（計算は正しいが、絵に出ない）。

### 「ないものを描かない」との関係

流れの印は、計算した流れを線にしたもので、計算していないもの（漂流物・砕ける波）ではない。ただし見まちがいを防ぐため、形は細い線だけ・色は1種類・凡例に「波や漂流物ではありません」と書き、切替で消せるようにする。

## 4. B　計算

### いまの計算で、誤った印象を与える点（氷室の見立て。上から重い順）

| # | 点 | どちら向きの偏りか |

| 1 | 沖の波の大きさを合わせる係数（gain）を、GPU からの読み戻しが届いた時点で直している。届く時点は、再生の速さ・パソコンの速さで変わる。**同じ条件でも結果が回ごとに変わる**（試験用の海浜で最大3.5%、アプリでは最大の深さで約2〜4%・最大の流速で約7〜8%。下の「訂正」） | 向きは決まらない（ばらつき） |
| 1' | 沖の水位の目標を、「1回に進める量」ごとに1つの値で与えている。防潮壁が切れる判定・最大値の記録も同じ。進める量は再生の速さで変わる | 同上 |
| 2 | 沖の波は、山が1つで、いちばん高い水位を900秒保つ仮定 | 深さ・浸水の長さは深め（安全側。ただし「公式に合う」という意味ではない） |

| 5 | 建物は格子1つぶんの壁。2mより細い路地は、ふさがるか2mの水路になる。海底は仮の形 | 場所による |

### B1　結果が、再生の速さやパソコンの速さで変わらないようにする（今回やる）

- 計算を、**決まった長さの区切り（16歩）**で進める。区切りの先頭で、沖の水位の目標を更新する。防潮壁が切れる判定・家が流される判定・最大値の記録も、区切りごとに行う。
- 沖の波の大きさを合わせる制御は、**計算の時間で15秒ごとの決まった点**だけで行う。その点では、GPU からの読み戻しが届くのを待ってから先へ進む（1〜2コマ止まる。×20 で約1秒に1回）。制御の式は今と同じ。
- 画面に出す「水の先端まで」などの読み戻しは、今までどおり待たずに行う（表示専用。計算へは戻さない）。
- 二段計算（内陸）では、広い計算の1区切りごとに、細かい計算を追いつかせる（組み合わせ方を固定）。細かい計算を起こす判定も、上の決まった点で行う。
- ×1 の再生は、1コマに最低1歩進める作りのため、実際は×1より速く進んでいる（コードからの計算で、格子768²で約×1.3、512²で約×2。実測はこれから）。時間の端数を持ち越して、×1 を正しくする。

氷室は GPU の中だけで制御を閉じる案も出したが、単純な「決まった点で待つ」案を採った（理由：制御の式を変えずにすむ／GPU の中で足し算すると1cm刻みの誤差が入る／読み戻しと制御が二重になる）。

### B3　仮定が結果をどれだけ動かすかを量る（今回やる。直すかどうかは結果で決める）

| 実験 | 比べるもの | あらかじめ決める基準 |
|---|---|---|
| 箱の大きさ | 同じ地点を、箱 1.5km と 3km で | 地点の最大の深さが **20%より大きく動けば**、沿岸の地点も二段計算にする（写真の細かさは保つ）。20%以内なら変えず、量った差を文書に残す |
| 高い水位を保つ時間 | 900秒 と 300秒 | **15%より大きく動けば**、条件の欄に「高い水位が続く時間を、長めに仮定しています」と出す。数字は変えない（安全側のため） |
| 防潮壁の切れ方 | その場で切れる と、120秒かけて切れる | 既定は「その場で」のまま（国の想定の考え方と同じ。弱めると到達が遅く・流れが遅く出る向きで、安全側でなくなる）。差は文書に残す |

### 数字はどう変わるか（見込み）

## 7. 巻き込む波・漂流物・防潮壁を越える水

| もの | やる／やらない | 理由 |
|---|---|---|
| 巻き込む波（砕ける波の唇） | **やらない** | この計算は、水面を「1枚の高さ」として解く。水面が折り重なる形は、原理的に出ない。絵だけ足すと、計算していない水を描くことになる。段波の前面そのものは、計算で出ている（切り立った水の壁として） |
| 漂流物（がれき・車） | **やらない** | 計算していない。確かめた模型もない。描けば「ここへ車が流れてくる」という、根拠のない具体的な情報に見える |
| 防潮壁を越える水 | **流れは、すでに計算している。** 落ち込みの飛沫は今ある飛沫のまま。新しく足すのは、越えた水の向きが読める流れの印（A1）と、越えた瞬間の自動減速（A2） | 越える流量は計算の中で出ている。滝の形（落ちる水の面）は、上と同じ理由で描かない |
| 「天端まで あと○m」 | **やらない** | 天端の高さも水位も、入力した仮定。差を出すと「越えなければ安全」と読まれる |

## 9. 「誤った安心をなくす」方針を崩さないために

- 「安全という意味ではありません」「猶予の時間ではありません」「揺れたら高い所へ」は、畳みの中に入れない（三枝が譲らなかった点）。
- 計算を変えて深さが浅く出る向きの変更（箱を広げる・防潮壁をゆっくり切る）は、量った結果と基準なしには入れない。入れる場合も、公式想定の数字は今までどおり並べて出す。
- 新しく足す絵（流れの印・道の線・道のりの帯）には、それぞれ「何であって、何でないか」を1文で付ける。
- 「あと○m」「○分後に到達」「間に合う」は出さない。
- 速さを自動で変えるときは、必ず文で知らせる。
