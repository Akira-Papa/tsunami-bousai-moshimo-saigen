# R2 オルテガ（A：水の流れ）第2ラウンド

## 1. 名指しの反論
**氷室 R1 33〜34行「主因は×20再生。直すのは再生」**　半分だけ賛成。賛成：波形が緩いのが原因ではない（公式1.75mm/s、こちら6mm/s）。反対：再生だけでは直らない。(1) 私の実測（704→766秒＝実3秒）では海は変わらず、越流後も1100秒で一面の茶色の板（`over_1100s`）。×5にしても、向きの手がかりのない板をゆっくり見るだけ。(2) **「先端300m以内で×5」は、氷室さん自身の数字で破綻する**。先端は300秒で約100m、700秒で約40m（0.15m/s）。300m地点は300秒より前なので、×5は700秒の越流まで400秒超を実時間80秒以上かけて待つことになる。距離ではなく出来事（越流・破堤）で切るべき（3-(c)）。

**三枝 R1 66行「凡例は『筋は水の流れる向き。速さではありません』で足りるか」**　足りない。旧 streak は fd と −fd で同じ絵で、向きの符号が出ない。新しい印は頭が明るく尾が消え、長さ＝速さ。凡例は3-(a)の文に差し替える。**同 #8「控えめ表示→見やすく（飛沫・濁りを減らす）」**にも反対。中身は飛沫を消し深さ色を強制（main.js:693-697）で、「見やすく」は嘘。「動きを減らす」にする。

**鳴海 R1 25・27行（札24・道路線・光の柱）**　全部を既定で出すのに反対。柱は加算合成の白で、白い流れの印と同じ明るさの語彙になる。3-(b)で優先順位をつける。

## 2. 鳴海への答え：水の上に道路線を描くか
**既定は描かない**。水は不透明（`a` は hp>0.1 で1、shaders.js:278）なので、地面の道路は隠れるのが正しい。水面に線があると「浮いた模様」で、深さを見誤る。切替「水の下の道を見る」（既定オフ）で、w_water が道路マスクを細く25%で重ねる案は可（テクスチャ1枚追加）。方向の手がかりは道路でなく流れの印が担う。

## 3. 議長への答え
**(a) 「ないものを描かない」に反するか**　計算した流れ（R2 の u,v）の可視化なので反しない。ただし誤読の防止が要る。保証：丸い点を作らず、長さ3m以上・幅の8倍以上の細い線のみ。大きさ・色は1種類、淡い青白。水面に寝かせ、乾いた所・壁の中・遅い所（sp<0.15）に出さない。視点が25m以内では薄めて間引く（目線の人影・柱と混ざらない）。粒子に個体の動きをさせない（寿命3〜5秒で入れ替え、密度は一様）。凡例：「白い細い線は、水の流れの向きと速さの目印です（計算した流れから描いた印で、波や漂流物ではありません）。明るい側へ進みます。長いほど速い。早送り中は見やすいよう動きを遅めにしています」。切替：表示欄に「流れの印」（既定オン）。

**(b) 優先順位**　1つの絵に出す線は最大3種。
- 既定オン：流れの印（薄め）、先端の線、「ここ」と避難場所の札（最大3）、海の高さの札、地点の柱（細く）。
- 距離で出る：いまの壁の水位線（200m以内）、町丁・駅の札（俯瞰は8件まで、近づくと増える）。
- 切替（既定オフ）：道路線（地面のみ）、道のりの帯（カードで道のりを選んだら自動オン）、速さ色、水の下の道。
- 色の担当：流れ＝白い細線、道のり＝緑の太い帯、道路＝暗い灰の地面線。再生の最初の3秒は札を薄く。

**(c) 自動減速は1規則に**　状態は3つ：①早送り（越流前。上限×60。「静かな海を早送り中」と出す）→②見どころ（越流・破堤の開始＝`coast.breached`>0、または先端が地点から150m以内で秒速0.3m超。上限×5）→③ふつう（先端が地点を過ぎて深さが落ち着く、または2分後。利用者の指定に戻す）。利用者が手で速度を選んだら、以後は自動で触らない。三枝の「いま何が起きているか」の文と同じ事象を使う。300m案は捨てる。

**(d) 60fps の根拠**　基準：水の描画は0.4〜1.5ms（bench.txt、この Mac）。粒子更新は6.5万スレッド・約6.5MB、PC 0.05ms未満。描画は尾約10m²、俯瞰で1本数十画素、PC +0.2〜0.4ms（推定、未測定）。スマホ（2^15）は4〜8倍遅いと仮定して +1〜3ms（推定、未確認）。測り方：water.mjs の止め撮り90コマ＋GPU待ちで、印の表示あり／なしを、PC768²・SP512²の俯瞰・地点・目線で。基準：PC +1ms、SP +2.5ms 以内。落とし方：65k→32k→16k（`mesh.count`、現行の maxSteps 減らしと同時、解像度より先）→尾を短く→距離で間引き→オフにして固定矢印（5章）。

**(e) 1人が今日〜明日で3つ**　①流れの印と時間のものさし（実装4〜5時間）、②自動減速の1規則（2時間。三枝の一行と同じ事象）、③先端セルの u,v 保持（氷室へ）と先端の細い線（1〜2時間）。壁の水位線・速さ色・固定矢印は後。鳴海のカメラ作り直し（3〜4時間）と取り合うので、どちらを先にするかは議長の判断。

## 4. 譲る点・譲らない点
**譲る**：速さ色・壁の水位線・固定矢印は後回し。控えめ表示では当面、印を止めるだけ。先端の矢印は元から不要。越流前の「あと○m」は三枝の文に任せる。
**譲らない**：①頭と尾で向きの符号を出す（引き波が読める）。②粒子は丸くしない。③自動減速は出来事で切る（距離では切らない）。④「流れの印」の切替は必ず残す。⑤動きを減らす設定でも、向きの情報を消さない（固定矢印は後でも、文字の「押し／引き」は残す）。
