# R1 鳴海 匠（D：3Dの動かしやすさ・地図の見やすさ）

実測：開発サーバーで名古屋・港町（n=512）を、PC 1440×900 とスマホ 390×844（タッチ）で操作。page.mouse と CDP の touch を送り、camera と controls.target を読んだ（画像・数値は scratchpad/narumi/）。再生はしていない。

## 2 地図として見づらい上位5
1. **近づくと写真がぼやける**。写真は z17＝約0.98m/px（region.js:32）。地点視点（84m）は1画素が画面12.7px。after_nagoya_pc_pin_*・impact_* の地面は水彩のよう。屋根も同じ写真（world.js:548）でぼける。
2. **建物が同じ箱**。琥珀色の「参考」が多数で、自分の家・学校が分からない。札は【指定】最大3件のみ（main.js:572）。after_nagoya_pc_over_700s。
3. **道・駅・地名がない**。after_inland_pc1440_4sim_1500s は名古屋駅の前でも札は「海の高さ」だけ。
4. **方位・海・自分の地点**。北の手がかりなし。「ここ」札は小さく、最大に引くと避難場所の札に埋もれる（pc_wheel_max）。最大に引くと上部が黒く欠ける（空の描画。原因は未確認）。
5. **避難場所の道のりと浸水の境**が3Dにない（道のりは2Dのみ）。内陸は灰青の写真と霧で、ピンクの浸水域が小さい。

## 3 直し方
**(a) カメラ**：MapControls型にする。main.js:428-432 に `screenSpacePanning=false`（水平に動く＝空・地下へ行かない）、左ドラッグ・1本指＝動かす、右ドラッグ・2本指ひねり＝回す、`zoomToCursor=true`。毎フレーム、注視点を計算範囲±L/2と標高+1mに、カメラを標高+1.5m以上に挟み、minDistance 8（目線のみ0.5）、maxDistance 4500→L×1.6、dampingFactor 0.05→0.12。pointerdown・wheel で camAnim=null（利用者が勝つ）。ダブルタップで、触れた地面へ0.6秒で半分寄る。回す＝今のOrbitを捨てるので、初見は「1本指＝回る」でなくなる。地図アプリと同じなので迷いは減ると見る。ドラッグ中だけ注視点の地面に十字を出す。
**(b) 部品**：右下（スマホは右上）に、方位磁針（針は az に追従・押すと北上）、＋/−、「◎地点へ戻る」。視点は「全体／地点のそば／立って見る／海側の建物」＋小さな絵。初回6秒だけ「ドラッグで動かす・2本指で回す／つまむ」（localStorage）。キーボード：canvas に tabindex=0・role=application・aria-label。矢印＝動かす、＋−＝寄る、Q/E＝回す、N＝北、0＝地点へ。視点を変えたら aria-live で告げる。
**(c) 注記と線**：bvmap は現在も読み込み済み（tiles.js:277-306）。**追加通信ゼロ**で `label`（町丁 annoCtg800・駅422・学校等885）と `road` を取れる。実測：名古屋駅のz16タイルで road 223本・label 13件（駅3）。道路名の属性はない＝道路名は出さない。label は CSS2D 札を最大24（駅・避難場所→学校等→町丁の優先）。距離でフェード（町丁600m・駅1500m）、6フレームに1回、画面矩形の重なりを優先順で消す。避難場所の道のりは brief の route path（brief.js:237-254）を地面に沿う幅3mの帯（緑＝指定、橙＝高い所）で。
**(d) 地面**：2048²のcanvasに道路（rnkWidthで太さ）を描いて写真に薄く重ねる（淡色地図の切替は見送り）。近景の写真ぼやけは z18化（約169枚・数MB増）より、道路の線とノイズの細部で補う。
**(e) 地点の印**：光の柱（半径1.5m・高さ60m・加算合成・距離で太さ補正）＋地面のリング。
**(f) ミニマップ**：PCのみ・後回し。スマホは面積が惜しい。
**(g) スマホ縦**：欄は既定で1行（深さ＋一言）にし、くわしくは下から引き出すシートに。ドックは再生＋視点の1段、速度は「×20」1つに畳む。目標：3Dの帯を45.9%→60%以上。構図は `camera.setViewOffset` で見える矩形の中心に合わせる。

## 4 重さ・SP・アクセシビリティ
道路canvasはGPU 16MB・初回描画のみ（実時間は未確認）。札はDOM24・6フレームに1回の投影。帯・柱は1描画。カメラ変更は0コスト。スマホは札12・道路canvas 1024²に落とす。キーボードだけで視点・北・地点へ戻る・寄る、が可能になる。動きを減らす設定は既存どおり（setView の瞬間移動）。

## 5 優先順位（1人・今日〜明日）
1. カメラ作り直し(a)（3〜4時間）。2. 部品・文言・キーボード(b)。3. スマホの欄の畳みと構図(g)。4. 道路線＋地名札(c,d)＋地点の柱(e)。5. 道のりの帯。
**やらないこと**：淡色地図切替、ミニマップ、道路名の3D表示（データなし）、写真z18全面化、回す操作の廃止。
**確かめたいこと**：氷室さんへ、浸水の境の線は何mで引くか。ミラさんへ、水が不透明になった所で道路線を水の上に描くか。三枝さんへ、視点4つの名前、初回ヒント、「道のり」凡例の文言、欄を既定で畳むことの合意。
