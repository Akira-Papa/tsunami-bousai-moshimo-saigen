# R2 三枝 糸（C：UI/UX・文言）名指しの反論

## 1. 反論
**氷室・オルテガ「速度を自動で×5に落とす」へ。** 利用者が選んだ×20を、告げずに奪う設計には反対。発動条件も食い違う（氷室＝先端が300m以内、オルテガ＝防潮壁を越えたとき）。1つに決め、「おまかせ」という選べる速度にしてほしい（3(c)）。
**オルテガ「防潮壁の天端まで、あと○m」へ。** 「あと0.4m」は「超えなければ安全」と読まれる。結果の「海の高さが天端より低い条件は、安全の根拠になりません」と逆向き。出すなら「この仮定の水位は天端より○m高い／低い（安全の根拠にはなりません）」とし、天端以下の条件では出さない。
**オルテガ凡例（約120字）へ。** 3D上では読まれない。常時は「白い細い線＝水の流れの向きと速さの目印（計算から描いた印。波や漂流物ではありません）」まで。「早送り中は線の動きを遅めにしています」は速度の通知側へ移す。
**鳴海「方位磁針・＋−・地点へ戻る・初回ヒント」へ。** スマホでは、＋−はピンチがあり、「地点へ戻る」は視点「ここの近く」と同じ働き。重複なので不要。視点ボタンの「小さな絵」も、行を高くするので反対（文字だけ、44px）。

## 2. 鳴海への答え
- **視点名（決定）**：全体／ここの近く／立って見る／海ぎわ。「立って見る」は鳴海案を採る。広域は「海から」。
- **初回ヒント**：タッチ「1本指で動かす・2本指でひねって回す・つまんで寄せる」。PC「ドラッグで動かす・右ドラッグで回す・ホイールで寄せる」。3Dの窓の下寄りに1回だけ。触れたら消す（最長6秒）。通知があるときは通知を先にする。
- **3Dの「道のり」凡例**：「緑の帯＝指定の逃げる場所までの道のり（目安）。橙＝標高が高い所まで。通れるとは限りません」。既定はOFF（「表示」に入れる）。水が来た所は帯を点線にする。水の上に実線が残ると「通れる」に見えるため。2Dの注（浸水する道も避けていません）は3Dにも要る。
- **右の欄の既定の畳み**：賛成。ただし「1行」でなく2行（3(b)）。

## 3. 議長への答え
**(a) 地点カード（スマホ、窓を地点選択直後だけ60%＝約506px）。** 最初の画面に残す行：
1. 地名・標高（30字内）。
2. 「公式想定：ここ1.3m・周り300m以内2.5m。備えは深い2.5mで」（約30字）。
3. 状態の一文（畳まない）：「地震から最も早くて約108分。猶予の時間ではありません」。条件つきの警告（浸水なし・範囲外・取得失敗＝「安全という意味ではありません」、ケース01が最大でない地域）は、この行へ合流させる。
4. 最寄りの【指定】1件：「A 名古屋港湾会館 道のり約320m・歩いて約6〜11分（目安・通れるとは限りません）」。道のりの注は、この1行に残す。
5. 畳みの入口：「ほか4件の逃げる場所・道のり・出典・ケース01の説明 ▼」。中身を書く（「くわしく」にしない）。畳みの中は、一覧、道のりの一覧、一般注（ほかのケース・川・堤防）、出典、3D条件の順。
一般注は畳み、状態に結びつく注は畳まない。これで読まれない危険は、条件つきのものには及ばない。

**(b) 右の欄（スマホ）は2行。** 1行目：「ここの深さ 1.22m」（数字28px）＋右に「公式 1.3m／周り2.5m」（15字・12px）＋「くわしく」44px。2行目（12px）：行動の一言。届く前は「届いていません。安全という意味ではありません」（23字）、1m以上は「巻き込まれると命にかかわります。高い所へ」（22字）。根拠文（内閣府・気象庁）は「くわしく」の中に残す。高さは約84px（いまは約200px）。

**(c) 自動減速の知らせ方。** 速さに「おまかせ」を足し、既定にする（先端が300m以内、または防潮壁を越えたら×5。水が引き始めたら戻す）。ドックの速さ欄に「おまかせ（いま×5）」と常に出す。切り替わったら、ドックの「いまの様子」行に8秒：「水が近づいたので×5にしました［×20のまま］」。［×20のまま］は44pxのボタンで、1回押せば固定になる。×1〜最速を自分で選んだ時点で自動は止まる（表示「×20 固定」）。通知は既存のtoastと別の行に置く（重ならない）。読み込み画面の「約2分」は「数分」に。

**(d) 390×844のpx割り振り（目標：3D 60%以上）。** 上の見出し（戻る＋地名44＋badge 40＋隙間8）92、欄84、隙間8、ドック110、下の隙間8で、3Dの窓は約542px＝64%。ドックは2行：1行目［▶44］［進み具合の帯＋いまの様子］［速さ］［結果］、2行目［全体｜ここの近く｜立って見る｜海ぎわ｜表示▾］。
足してよい：方位磁針（44px・3Dの窓の右上）、初回ヒント（一時）、進み具合の帯（時計の注の置き換え）。だめ：スマホの＋−、地点へ戻る、ミニマップ、視点の絵、常時の凡例。PCは＋−を右下に足してよい。数字は計算上の見積り。実機は未確認。

**(e) 上位3つ。** ①スマホの3D画面の再構成（欄2行・ドック2行・通知の置き場・いまの様子1行）。②地点カードの4行化と文言の置換。③カメラの小改修（操作したら視点移動を止める・注視点の範囲制限のみ）。1本指＝動かす、への作り直しは、その次。水の流れの粒子は、全体ではオルテガ案が最優先で、私は譲る。

## 4. 譲る点／譲らない点
譲る：視点名は「立って見る」、方位磁針、1本指＝動かす、欄の既定の畳み、自動減速（「おまかせ」として）。
譲らない：上の帯の「揺れたら高い所へ」、「安全という意味ではありません」「猶予の時間ではありません」を畳みに入れないこと。速度を無告知で変えないこと。スマホの部品を足して3Dを60%未満にしないこと。44px。
