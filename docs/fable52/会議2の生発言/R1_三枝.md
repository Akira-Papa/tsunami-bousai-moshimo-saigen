# R1 三枝 糸（C：UI/UX・文言）第1ラウンド

実測は 390×844（ガーデンふ頭を選択）。

## 1. つまずく所 上位7つ

1. **地点選択カードが長い**（`#pick-scroll`、after_sp390_2selected）。窓は高さ456px（画面の54%）、中身は約4,900px＝窓の約10枚ぶん。公式想定は870px、逃げる場所は1,320px、道のりは2,279px、3Dの条件（海の高さスライダー）は4,133px。最初の1枚には「地名と公式想定の頭」しか入らず、最も大事な「逃げる場所」が入らない。
2. **注意の重複**。同画面で「市町村」7回、「確かめ」6回、「仮定」6回、「ケース01」5回、「予測ではありません」2回。「安全という意味ではありません」は1回で適正。
3. **3D画面が狭い**（after_sp390_4sim_660s）。上の帯＋札＋HUD＋ドックで画面の約7割が埋まり、3Dが見える窓は約27%。通知（`#toast`）がその窓の真ん中に重なる。ドックは5段。
4. **ボタン名が内部の言葉**。「衝突」「目線」「地点」は何が起きるか分からない。「控えめ表示」は中身（飛沫を消し、深さ色を強制）が分からない。「逃げる場所の候補を色で示す」（`#tg-tall`）は、P0-5で「参考」に格下げした橙の建物なのに「候補」と名乗り、方針と食い違う。
5. **▶前後の案内**。自動再生は1.5秒後（main.js:1113）なのに、HUDは「▶ を押すと…」。段階の手がかりは時計と`#phase`だけで、進み具合は読めない。
6. **誤タップ**。`#speeds`の「最速」が×60の隣にあり、押すと一気に終わりへ飛ぶ。`.seg button`は高さ40px、`.presets button`34px、`.toggles label`32px で44px未満。
7. **用語のぶれ**。「海の高さ」は潮位と混ざる。「高い所」が、標高の高い場所・高い建物・道のりの終点の3つの意味で使われる。結果ダイアログでは公式想定と「備えは」の段落が同じ数字を2回言う。

## 2. 直し方

### 地点選択カード（スマホ）
最初の1枚は4つだけ。①地名・標高 ②公式想定（備えは深いほうの1行）③いちばん近い【指定】逃げる場所1件（道のり・歩く時間）④いまの3D条件1行「3Dで見る海の高さ：5.0m［変える］」。下の段は今のまま「この地点で、3Dで再現する」。
畳むもの：逃げる場所の残り、道のり、ケース注記、くわしい条件、出典（［変える］で海の高さスライダーが開く）。
畳んでも残す最小限：上の帯の「揺れたら高い所へ」、公式想定の下の「逃げるまでの猶予の時間ではありません」、浸水なし・範囲外・取得失敗の3状態には必ず「安全という意味ではありません」。「市町村で確認」は逃げる場所の見出しの下に1回だけ。

### 3D画面のドック
- PC幅（1行）：［▶］［進み具合の帯］［速さ ×20▾］｜視点［街ぜんたい｜ここの近く｜人の目の高さ｜海ぎわの建物］｜［表示▾］［結果を見る］
- スマホ幅（3行）：1行目 ［▶ 44px］［進み具合の帯］［速さ▾］、2行目 視点（4等分・44px）、3行目 ［表示▾］［結果と、このあとすること］。時計の注は「？」に畳む。「最速」は速さの奥へ。
- HUD（スマホ）：「ここの深さ 0.00m」＋ひとこと1行＋公式1行。長い根拠文（`depthSay`）は「くわしく」の中へ（出典は残す）。

### 最初の▶まで
読み込み画面の最後に「このあと約2分（×20・未確認）、津波が街に入る様子を流します。▶で止められます」。開始前の帯は「まもなく始まります」。自動再生は残す（動きを見せるのが目的）。省電力設定の人にだけ、画面中央に［▶ 再現を始める］を出す。

### いま何が起きているか（1行・`#phase`を置き換え）
静かな海：「沖はまだ静かです」／上昇：「沖の海面が上がっています」／防潮壁を越えた：「防潮壁を越えました」（9秒）／陸に水：「陸に水が上がりました」／地点に到達：「ここに水が来ました（深さ1.2m）」／保持：「高い水位が続いています」／引き波：「水が海へ戻っています」（水が残る土地は「海は下がっても、ここの水は残ります」）／終了：「再現はここまで。実際はくり返し来ます」。事象は既存の`st.*`と`coast.front`で取れる。

### 時間の見せ方
主役は帯：「静か→上がる→続く→引く」を**等しい幅の4区画**にして、現在の区画の中だけ進める（長さを時間と読ませない）。時計は帯の右端に「再現の時計 11:15」とだけ書く。

## 4. 変えてはいけないもの／他の3人へ
変えない：上の帯の「揺れたら高い所へ」、公式想定の「猶予の時間ではありません」、浸水なし・範囲外・取得失敗の3状態の注、「予測ではありません」。到達の時刻（○分後）は出さない。出典と数字の文は変えない。#16は幅で出す案で、専門家の確認が要る。
氷室さんへ：到達時刻を出さずに「水の先端まで約300m」「進み具合の帯」を見せてよいか。距離は猶予に読まれないか。
オルテガさんへ：流れの印の凡例は「筋は水の流れる向き。速さではありません」で足りるか。
鳴海さんへ：視点ボタンの名前（#4〜#7）、カード窓を地点選択直後だけ画面の60%にする案、通知を3Dの窓の外へ出す案。

## 5. 優先順位
1. 地点選択カードを4点に絞り、残りを畳む（最初の1枚に「逃げる場所1件」を入れる）。
2. 3Dドックを3行に圧縮し、通知を3Dの窓の外へ（3Dの見える面積を約27%から4割へ）。
3. 視点ボタン・「逃げる場所の候補」の名前を直す（方針と一致させる）。
4. 「いま何が起きているか」1行と、等幅4区画の進み具合の帯。
5. 「最速」の誤タップ防止と、44px未満のボタンの44px化。
