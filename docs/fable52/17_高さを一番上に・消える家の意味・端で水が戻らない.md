## 2　3Dで建物が消えていくのは、何か

**「木造の家が、津波で流された」という表現**（不具合・遠くの省略・水面下を隠す処理ではない）。

| | 内容 |
|---|---|
| どの建物が | 木造の家（PLATEAU の構造が「木造」。構造のデータがない所は、普通建物の区分から木造と推定したもの）。鉄筋コンクリートなどは消えない |
| いつ | その家のまわり（となりのマス）の水の深さが **2m 以上**になった時 |
| 計算では | その家は壁でなくなり、水が通り抜ける（`src/sim/swe.js` の `washDetect`・`washApply`） |
| 絵では | 家が、高さ約0.5〜1mの茶色のがれきにつぶれる（`src/render/world.js` の「木造家屋の流失」）。水が2m以上あるので、がれきは水の下に隠れ、**消えたように見える** |
| 根拠 | 気象庁の目安「浸水2mで木造家屋は全面破壊」（首藤の津波強度階級による） |
| 切り方 | 「3Dの条件を変える」→「くわしい条件を変える」のチェック（はじめはオン） |

本人のお考え（流されるという意味なら、そのままでよい）のとおり、動きは変えていない。意味が伝わるように、言葉を足した。

| 足した所 | 言葉 |
|---|---|
| 最初の1棟が流された時の1行（下の操作欄の「いまの様子」） | 「木造の家が流され始めました。**消えた家＝流された家です**（深さ2m以上・気象庁の目安）」。スマホ幅は「家が流されました（消えた家＝流された家）」 |
| 「表示」を開いた中の説明 | 茶色の見本つきで「**消えた家＝流された木造の家**（深さ2m以上で流される、とする目安）」 |

## 3　再現の四角の端で、水がはね返って戻るのを直した

### 原因

`src/sim/swe.js` の、四角の端の扱い。波を入れる沖の帯のほかは、**端を「鏡の壁」にしていた**（以前の判断：「四角の外も同じように浸水する」とみなす。端を開けると、長く水位を保つ間に端が排水口になる、という理由）。このため、陸に上がった水が四角の端に着くと、そこで積み上がり、段波になって四角の中へ戻っていた。

### 直し方

| 端にあるもの | 直す前 | 直した後 |
|---|---|---|
| 陸（はじめに乾いている所。流された家の跡も） | 鏡の壁（水は出られず、はね返る） | **開いた端**：着いた水は、そのまま外へ出ていく。外から中へは入れない |
| 波を入れる沖の帯 | 開いた端（出るだけ） | 変えていない |
| はじめから水のある所（沖の帯の外の海・川・港） | 鏡 | **鏡のまま**（下の「いちど試してやめた形」） |

**いちど試してやめた形**：はじめは、端をすべて開いた。すると、陸の水だけでなく海そのものが四角の横から漏れ、名古屋港で海岸の水位が開始300秒で 2.31m→1.70m に下がり、到達が 815秒→983秒 に遅れ、波の大きさを合わせる係数が上限まで上がった。本人の指摘は「陸を進む水が端でぶつかって帰ってくる」ことなので、陸の端だけを開く形にした。

## 6　確かめていないこと・残っていること

- 端を開いたことで、**四角の外へ出た水は消える**。四角の端に近い場所では、深さが実際より浅く出るおそれがある（外で行き止まりになって戻る水を、再現しないため）。地点は四角のまん中（端から約750m）にあるので影響は小さいが、0ではない。
- 確認した地点は、名古屋港・高知 種崎・名古屋駅の近くの3つ。ほかの地点の数字の変化は測っていない。
- 二段の計算の広い四角（内陸の地点）で、陸の端から水が出る場面は、今回の3地点では起きていない（名古屋駅の近くは、水が届かない）。
- 実機のスマートフォンでの確認はしていない。
