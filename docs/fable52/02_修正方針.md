## 1. ねらい

修正前のサイトは「水がどう来るか」は見せるが、見終わった人が **何をすればよいか** を持ち帰れない。
さらに、次の3つが「危険な安心」を生んでいた。

| 危険 | 修正前の実際 |
|---|---|
| 「届かなかった」が安全に読まれる | 結果の最上段が「今回の仮定では到達せず」。計算は約39分ぶんだけで、公式想定（1.3m・地震から約108分）は下の灰色の枠 |
| 「13分後」が猶予時間に読まれる | 人工の海底と計算範囲で決まる値なのに、公式の「地震から108分」と同じ大きさで並ぶ |
| 橙の「高い建物」が行き先に見える | 高さと構造だけの機械判定。入れるか・開いているかは分からないのに、3D上に番号つきの札 |

加えて、WebGPU がない端末は「表示できません」の行き止まりで、何も持ち帰れなかった。

## 3. やらないこと（理由）

| やらないこと | 理由 |
|---|---|
| 海の高さを3通りで計算して幅で見せる／第2波／計算窓の延長 | 倍率に根拠がない。数字が増えると小さい値が安心の材料にされる（真壁が自ら取り下げ） |
| Service Worker | 古い津波高・避難場所が端末に残る危険。1日で検証しきれない |
| WebGL2 や CPU で浅水方程式を解く | 検証していない数字を出すことになる |
| 標高だけで「海の高さ以下」を塗る簡易浸水図 | 流れも防潮壁も無視し、公式と食い違う |
| main.js の大分割・遅延読み込み | 回帰の危険に対して利用者の得が小さい。ゲートを throw しない形にすれば足りる |
| 「安全」「大丈夫」「浸水しない」の表示、点数づけ | 根拠のない断定 |
| 湛水期間「数か月」などの数字 | 一次情報で確かめていない。期間は書かず「排水されるまで長く続くことがあります」 |
| 公開（S3）・push・main へのマージ・応募資料の書き換え | 本人の指示があるときだけ |
