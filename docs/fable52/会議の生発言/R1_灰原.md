# R1 灰原ことは（UX・アクセシビリティ・やさしい日本語）

基準は「30秒で何のサイトか分かり、3分で自分の行動を1つ決められる」。いまは前者はほぼ満たし、後者が満たせていない。

## ①いちばん危ないと思う点 上位3つ

1. **行動の呼びかけが最下部に埋もれ、しかも1行だけ。** index.html:180 の `.call` と :181 のリンクは、結果モーダルの比較表・建物表・木造流失・長い注意書きの後ろにある（before_pc1440_6result_bottom.png／before_sp390_6result_bottom.png でようやく出る）。スマホは3画面分スクロールが必要。しかも「確かめてみませんか？」は任意の誘いで、「いま何をするか」が空欄。「今回の仮定では水は到達せず」「浸水なし」（sp390_5result）を最初に見た人は、安心して閉じかねない。
2. **初見の導線が途切れる。** main.js:44 の `scrollIntoView({block:'start'})` で、地点選択後にカードの先頭（題名・リード文・「予測ではありません」）が画面外へ押し出される（sp390_2selected.png は「海の高さ」から始まり、題名がない）。同画像では地理院の出典ボックスがカード下端に重なり、「再現する」ボタンの位置が分かりにくい。設定は5項目（T.P.、天端、満潮、破堤、格子）を一度に出し、:47 や :50 は専門語が長文。初心者が決められるのは「地点」と「海の高さ」だけのはず。
3. **3Dに頼る構造で、見えない人・弱い端末に代替がない。** WebGPUなしは「表示できません」とリンク1本で行き止まり（nogpu_sp390）。結果の文章版も #r-read（:653）の読み上げ用1行だけで、画面上は11px・灰色の脇役。HUDは9項目＋建物リスト＋注意書き（sp390_4sim_660s は画面の半分がHUD）で、スマホでは3D自体が見えない。

## ②提案

1. **結果モーダルの冒頭に「あなたの行動カード」**（結果画面・小〜中）。見出し「このあと、あなたがすること」に3行：①「強い揺れ・長い揺れを感じたら、これを見ずに、すぐ高い所へ」②「ここから最も近い逃げ先：○○（約190m）」（既存の evac／tall を流用）③「家族に話す：逃げる場所と集合場所」。ボタン「ハザードマップで逃げ先を確認」。`.call`は20px・太字・上段へ。効果：3分で行動を決められる。**小**。
2. **「水は来なかった」結果の言い換え。** 到達しなかった時は最上段に「この条件では、ここまで水は届きませんでした。ほかの条件・川・堤防の破損では届くかもしれません。安全という意味ではありません」。:641 の `<small>浸水なし</small>` は同様に補う。誤った安心の防止。**小**。
3. **設定を二段に。** 初期は「海の高さ」と「この地点で再現する」のみ。残りは `<details>`「くわしい条件（専門家向け）」へ折りたたむ。T.P.は「T.P.（東京湾の平均海面を0とした高さ）」、天端は「防潮壁の上端」とやさしく書く。選択後は `scrollIntoView` をやめ、題名は残す。**小**。
4. **スマホのHUDを「深さ＋ひとこと」の1段に。** 既定は h-now と say のみ表示、残りは「くわしく」ボタンで展開。ドックは再生・速度、視点、結果のみ。トグル4つは「表示設定」へ。ボタンは44px以上、10〜11pxの文字は12px以上（.gauge i、.stats dt、.fineprint、.lbl.tick）。**中**。
5. **モーダルとキーボード。** 開く時に見出しへフォーカス、Tabを内部に閉じ込め、Escで閉じて「結果を見る」へ戻す（main.js:518–521 にはEscape処理なし）。フォーカス環を `:focus-visible { outline:3px solid #fff; outline-offset:2px }` で全ボタンに明示。`#h-say` は `aria-live="polite"` で段階変化（0.3m・1m・2m）のみ読み上げ（毎フレームは不可）。**小**。
6. **文章版の結果を既定で見える位置に。** #r-read を「文章で読む」として結果の2番目に置く。WebGPU非対応画面にも、同じ地点の文章版（標高・公式想定の最大浸水深・逃げ先候補）を出す。行き止まりをなくす。**中**。
7. **共有・印刷。** 結果に「家族に送る」（地点・海の高さ・要点3行を入れたURL、`navigator.share`）と「印刷／PDF」（`@media print` で要点と逃げ先のみ）。「もしも再現・予測ではありません」を必ず添える。**中**。

## ③やるべきでないこと
- 結果に「安全／危険」のラベルや点数を付けること（根拠なき断定）。
- 数字を足して画面を賑やかにすること。引き算が先。
- 色だけの凡例を増やすこと（`.lbl.here` の白×#e2574c は3.68:1で12px太字では不足。計算上、ink-3 は5.39:1で通るが半透明パネル上では変動する）。
- 「安心」「大丈夫」の語、恐怖を煽る演出。
