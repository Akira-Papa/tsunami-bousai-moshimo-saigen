# R1 カシワギ（性能・配信・フォールバック）

数字は dist の実測と before_report.json（ヘッドレス）。実機スマホは未計測。

## ① いちばん危ない点 上位3つ

1. **WebGPU なしで行き止まり、しかも重い JS だけ落ちる。** main.js:25-26 の top-level await が全体を止めます。静的 import（2,11-13）で three/webgpu 入りの 2.1MB（gzip 588KB）が非対応端末にも落ち、地図 picker も 32 行で作られず出ません。154,165 の renderer 生成と init は try の外で、アダプタは取れても init が失敗すると固まります。
2. **メモリと端末ロスト。** swe.js:119-140 は vec4 f32 を約10本持ち、格子 512²で約42MB、1280²で約262MB。内陸ネストは広域 1024²（約168MB）が加わります（N は main.js:209 で最大1280）。写真 canvas は38〜67MB。device.lost の処理は src に皆無で、862-866 はループを止めるだけ。タブ復帰後の白画面が起こり得ます。
3. **失敗時の表示が人を誤らせる。** main.js:76,237 は利用者が直せない「?demo=1」を案内し、再試行がありません。official.js:23 は通信エラーを握りつぶし、main.js:331 が「未確認（収録外）」と出します。圏外が対象外に見えます。178 の中断は fetch を止めません。

## ② 提案

1. **「2Dで確かめるモード」**（新規 src/flat.js）。GPU 不要で再利用できるもの：picker.js、plan.js の tsunamiHeightAt、official.js の loadOfficialCells、tiles.js の loadBuildings と loadDemMosaic、避難場所データ。地図に内閣府100m格子を0.3／1／2mで塗り、地点の公式最大浸水深・到達時刻・標高・300m以内の避難先を一覧にします。文言は「再現」でなく「公式想定の表示」。効果：非対応端末でも行動に届く。重さ**中**、回帰リスク低。
2. **main.js を分ける。** 起動・選択・設定欄だけを残し、GPU 判定は await せず Promise にします。154-176、191-246、251以降は src/gpu-app.js へ移し、実行ボタンで `import()` します。効果：地図が先に出る（削減量は未計測）。重さ**中**、回帰**中**（共有変数 `app` と `$`）。
3. **judgeTall と distToRing（377-401、末尾）を src/data/evac.js へ。** 2Dと3Dで判定を共通化。重さ小、回帰低（名古屋の候補リストが修正前後で一致することを確認）。
4. **device.lost・init失敗・復帰対応。** `renderer.backend.device.lost`（r186で要確認）を拾い、地点と条件を保ったまま「再読み込み」「2Dで確かめる」を出します。重さ小〜中、回帰低。
5. **中断と再試行。** fetchOk（tiles.js:19）に AbortSignal を通し、失敗画面に「もう一度」を置き、331行は通信失敗と収録外を分けます。重さ小、回帰低。
6. **外部フォントをやめる。** index.html:9-10 の描画ブロックを、システムフォントと ui-monospace に替えます。圏外や社内ネットで崩れず、通信も減ります。重さ小、回帰小（字面が変わる）。
7. **最小の Service Worker。** 本体と tsunami_h.json・municipalities.json（計484KB）のみ。電波が弱い避難所でも起動と津波高の初期値まで届きます。地理院タイルは対象外。重さ中、回帰中（更新の取り残し）。

## ③ やるべきでないこと

- 無GPU向けに WebGL2／CPU で浅水方程式を解く。計算シェーダの作り直しで、検証不足の数字を出す危険があります。
- 標高だけで「海の高さ以下を塗る」簡易浸水図。流れも防潮壁も無視し、公式と食い違う危険な安心感を生みます。
- 地理院タイルの一括オフライン保存、格子256²への切り下げ（数字の意味が変わる）。
