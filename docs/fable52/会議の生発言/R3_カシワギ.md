## (2) 実装者が見落としそうな落とし穴（3つ）
1. **MapLibre へのレイヤー追加。** picker.js:84 の `isStyleLoaded()` が false のとき `once('load')` で待つ書き方は、ラスタタイル読込中に再度呼ぶと二度と発火しません。公式セルも避難場所も、`load` 後に空の source と layer を1回だけ作り、以後は `setData` にします。公式セルの取得は表示範囲のタイルに限り、zoom12未満では出しません。全域は14MBです。
2. **失敗の扱い。** official.js:7 は `??=` で失敗した Promise も固定し、再読込まで取り戻せません（plan.js:8、tiles.js:214 も同様）。official.js:23 は1タイルの通信断で Promise.all 全体が落ちるので、タイルごとに「あり／空／失敗」で返します。skhb05 の 404 は「データなし」で、失敗は別扱いです。z10 タイルは約38km四方なので、1km 以内の検索は縁の近くで最大4枚になります。
3. **カードが planDomain に巻き込まれる。** main.js:45-48 の Promise.all と 71-78 の早期 return により、計画が失敗（far／no-sea）すると、後ろに足したカードが出ません。カードの描画は別系統にし、token 照合（49行）は両方に掛けます。
