# R3 権田フミ（最終確認）

## (1) 裁定への意見

- **裁定1：同意。**「再現の時計」の mm:ss が残ると「あと何分」に読まれるので、結果の「水が来たのは○分」も消すこと。公式の「約108分」にも、「1cm（足首より浅い）でも道は歩けなくなります」を添える。
- **裁定4：条件つき同意。**名前と住所は現場の言葉として良い。ただし1kmは徒歩で、ゆっくり歩く人には遠い。300m以内と、それより遠いものを見出しで分け、遠い側に「歩く人によっては間に合わないことがあります」と書く。「避難所」とは書かず「津波から逃げる場所（指定緊急避難場所）」。避難所は泊まる所で、別物である。備考欄（屋外か、何階以上か）があれば出す。
- **裁定6：同意。**欄の確定案：
  ①「まず逃げる場所（建物の名前と、何階まで上がるか）」
  ②「離ればなれの時に会う場所（迎えには戻らず、自分が先に逃げる）」
  ③「手助けが要る人と、誰が手を貸すか（名前を書く）」
  欄の下に「この紙は予測ではありません。強い揺れを感じたら、すぐ高い所へ」を印刷する。

## (2) 落とし穴 3つ

1. **0件と取得失敗の混同。**通信に失敗すると「見つかりませんでした」が出る。圏外の人はそれを「近くに無い＝ここは来ない」と受け取る。0件と失敗は別の文言にする。
2. **緑でも入れない、海側へ向かう。**指定でも夜は施錠、川・橋・線路を渡る道のり、海に近づく方向は、データにない。直線距離だけが並ぶと、一番近い所へ走る。カードに「入口・開く時間は自治体で確認」を毎回付ける。
3. **避難メモの保存。**端末内の保存は、履歴を消すと消える。印刷しない人は、書いたことを失う。要配慮者の名前を書いた紙を玄関に貼ると、人目に触れる。「消えることがあります。印刷して家族で持ってください」「貼る場所に注意」と書く。
