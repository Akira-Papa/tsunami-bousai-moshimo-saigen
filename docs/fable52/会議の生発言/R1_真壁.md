# R1 真壁 澪（津波工学・浸水数値計算）

## ① いちばん危ないと思う点 上位3つ

**1. 「到達せず」と「13分後」が、計算の都合の数字なのに現実の数字に見える。**
- 結果画面は「今回の仮定では到達せず」（main.js 632）、読み上げも「水は到達しませんでした」（653）と断定する。計算の窓は約39分（swe.js 472：立ち上がり600＋高水位900＋引き600秒）で、公式は到達が1〜2時間後、継続は数時間である。窓が短くて届いていないだけかもしれない。docs/05は、富田町で再現が未到達なのに公式は2.6mだったと自ら記している。これが最も危険な「安心」である。
- HUDの「押し波開始から到達 13分後」（563、before_pc1440_5result.png）は、人工の海底（d=3+s/8）と計算領域の広さで決まる値で、物理的な到達時間ではない。「あと13分ある」とも「108分ある」とも読まれる。
- 時刻の基準が違うとは書いてあるが、結果画面の2つの数字（13分／108分）は同じ大きさで並ぶ。

**2. 入力は単一の一様な長波なのに、公式の1ケースと比べて「差」を論じている。**
- 初期値の海の高さは11ケースの最大（画面に明記）だが、比較する公式の浸水は ケース01 だけである（README）。波形も1波の台形（swe.js 478–489）で、第2波以降・最大波が遅れて来る性質がない。再現が公式より深い（1.87m対1.27m、6result_bottom）のも浅いのも、まず包絡と1ケースの違いで説明が付く。誤差ではない。
- 防潮壁は岸線に置いた近似で、浸水の「有無」を決める。スライダーで海の高さを天端以下にし「破堤しない」をONにできる（index.html 38–50）。その結果を「届かない」と見た人は、壁が壊れない世界を安全と学ぶ。

**3. 避難候補の「水位＋2m」（main.js 385）が、安全の線のように読める。**
- 水位は海岸側の最大水位で（669）、建物の屋上に入れるか、耐震基準、開口部、漂流物は見ていない。ラベルは「高い建物」「避難場所（津波）」（399）で、橙を「逃げ込んでよい」と読ませかねない。高さは屋根の高さで、人が上がれる床ではない。
- 実行前は「海の高さ5.0m」で判定し、実行後に5.9mへ変わる（before_pc1440_4sim_660s.png と 5result.png）。候補が途中で入れ替わる説明がない。

## ② 提案

1. **「到達せず」を言い換える。** 結果画面・読み上げ（632, 653）。「この計算の時間（約○分）の間は、この地点に水は届きませんでした。届かないという意味ではありません。公式想定は○mです」。公式が浸水ならこの文を赤字で先頭に出す。効果：最大の危険な安心を消す。重さ：小。出典：不要。
2. **到達時刻の見せ方を変える。** HUD（563）と結果の「水が来たのは」（634）。「約13分後」を「計算上の経過 13分（現実の到達時間の目安ではありません）」に、公式は「地震から約108分（ケース01・1cm）」に分け、別の枠に置く。効果：時刻の誤読を防ぐ。重さ：小。出典：公式は内閣府2025（既出）。
3. **「公式との差」の読み方を一文で足す。** 結果の比較枠。「再現は11ケースの最大の津波高を1つの波で入れています。公式の枠は1ケースだけです。差は誤差ではなく条件の違いです。**深いほうを備えの数字に**」。重さ：小。出典：内閣府2025（既出）。
4. **海の高さが天端以下・防壊れなしのときに警告を出す。** 選択画面。「防潮壁が壊れない設定は、実際の想定にはありません。内閣府・愛知県は越えたら壊れると仮定しています」。「届かない」結果にも同じ注記を付ける。重さ：小。出典：docs/04の一次情報（愛知県・内閣府）。
5. **避難候補の文言を弱め、足りない確認を並べる。** HUD（419–421）と結果表。「橙＝高さが水位＋2m以上の建物。**入れるか、上がれる階か、耐震か、は未確認**」。判定を「候補」と呼び、順位を消して距離順に。「＋2m」には「余裕2mは本サイトの仮の目安で、公式の基準ではありません」。重さ：小。出典：津波避難ビルの国のガイドライン（内閣府2005）の階数基準は**未確認**。
6. **水位の想定を複数見せる（Fable向き）。** 結果画面。海の高さを既定の0.5倍・1倍・1.3倍で3回走らせ、地点の最大深さを3つ並べる（「幅で考える」）。再現の不確実性を数値で示す。重さ：大（計算3本。軽量格子で約1分ずつ）。出典：倍率は仮で、根拠なしと明記。
7. **到達判定を現実寄りにする。** 同じ波形に第2波（1.3倍、60分遅れ）を足す選択肢と、計算窓を90分にする選択肢。重さ：中（swe.js の波形と時間）。出典：Nankai の継続時間は未確認。

## ③ やるべきでないこと
- 「安全」「浸水しない」「安全な建物」の断定。「到達せず」の単独表示。
- 再現の時間を公式の到達時間と同じ表に並べ、差を縮める調整（較正で公式に合わせて見せること）。
- 0.3m/1m/2mの目安文（542–546）の数字を、出典なしに増やすこと。1m「命の危険」と0.3m「避難困難」は、出典を一次確認するまで「目安」と明記したい（私は**未確認**）。流速も力に効くので、深さだけでの区分は避けたい。
- 木造流失の棟数を、構造の推定のまま大きな数字で出すこと。644棟は過大側の仮定（既に注記あり）で、見出しを「多めに出る仮定」にしたい。
