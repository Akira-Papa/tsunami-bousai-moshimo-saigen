# R1 権田フミ（現場・避難計画）

見たもの：index.html、main.js の結果文言、before の PC/スマホ画像（5result、6result_bottom、4sim_660s、3ready）。

## ①いちばん危ないと思う点 上位3つ

**1. 「到達せず」「まだ届いていません」が、安心に化ける（before_sp390_5result.png、before_sp390_4sim_660s.png）**
スマホ結果の最上段は「今回の仮定では到達せず」「浸水なし」「水が来たのは ー」。この画面を見た人は「うちは大丈夫」と読む。ところが同じ画面の下では、公式想定は1.3m・地震から約108分である。現場で聞く誤解は「ここは来ないと出た」「108分もあるから、揺れても片付けてから動く」である。仮定の波高1つで出た結果を、地点の安全の証明に読んでしまう。「来ない」の隣に「公式は来る」が並ぶ順序が逆で、公式想定は一番下の灰色にある。

**2. 「高い建物（避難候補）」の橙ラベルが、行き先の指示に見える（before_pc1440_4sim_660s.png、before_pc1440_5result.png）**
地図上の「2. 高い建物 約80m」は目立つ。実際は商業施設や文教厚生施設で、夜間は閉まり、鍵がかかり、屋上は出られないことが多い。高さと構造だけの機械判定で、自治体の協定ビルかは分からない。「予測・推奨ではありません」の小さい注記では、橙の看板の強さに負ける。住民は一番近い橙へ走る。入れない建物の前で立ち往生し、そこで水が来る。

**3. 「いつ動くか」「どう行くか」「誰と決めるか」がどこにもない（結果モーダル全体）**
結果で分かるのは水の深さと到達時刻だけである。避難の道のり、歩いてかかる時間、家族の集合場所、夜や雨、歩けない人の話がない。最後の1行が「ハザードマップを見てみませんか」で、行動が「見る」で止まる。一番大事な「揺れたら結果を待たず逃げる」の一文はモーダルの下端で、スマホでは長い文章を最後までスクロールしないと出てこない（before_sp390_6result_bottom.png）。

## ②提案

**提案A　揺れたら逃げる一行を、最初の画面から常設する**
- 画面：地点選択カード（before_pc1440_1pick.png）の導入文の直下、シミュレーション画面の上部バッジ、結果モーダルの最上段。
- 文言：「このサイトは練習です。強い揺れ、または長くゆっくりした揺れを感じたら、津波の結果を待たずに高い所へ。」
- 効果：伝わる位置が最下部から最上部に変わる。重さ：小。数字なし。

**提案B　「到達せず」の書き換え**
- 画面：結果モーダルとHUD。「今回の仮定では到達せず」を「この仮定の波では水は届きませんでした。ここが安全という意味ではありません。」に。公式想定が浸水ありなら、その行を先に出し、色も警告色にする。
- 効果：誤解の最大要因を直接つぶす。重さ：小〜中（表示順の入れ替え）。数字は画面の値のみ。

**提案C　避難候補ラベルを3段に分ける**
- 画面：地図ラベル、HUD、結果の表。
- 文言：緑は「津波の避難場所に指定（国土地理院データ）」。橙は「高い建物です。入れるか、開いているかは分かりません。」を毎回ラベル近傍に出す。橙の色を落とし、緑とは明確に格下げする。
- 効果：「走ったが入れない」を減らす。重さ：中。出典：指定緊急避難場所データ（国土地理院、既使用）。

**提案D　「この画面のあとにやること」3行カード（結果モーダル先頭）**
- 文言：「①家族で集合場所と逃げる先を1つ決める　②そこまで実際に歩いて時間を測る（夜・雨の日も）　③歩けない人は誰が、どう運ぶかを決める」。
- 効果：「で、うちはどうする」への答えの型を渡す。重さ：小。数字なし。歩行速度などは入れない。

**提案E　歩く距離の目安は出すが、時間は出さない（または出典付きで条件を併記）**
- 画面：避難候補の「約190m」の横。
- 文言案：「直線距離です。道のりは長くなります。夜・雨・混雑では遅くなります。」時間表示をするなら、歩行速度は出典（国土交通省などの避難速度の資料）を議長が裏取りしてから。**現在は未確認。**一般に高齢者・要配慮者は想定より遅い、という注意文だけは出典なしで入れてよい。
- 効果：「190mなら3分」の暗算を止める。重さ：小。

**提案F　ゼロメートル地帯の長期湛水を、結果とは別の目立つ札に**
- 画面：結果モーダルの上部（現状は長文の中間）。
- 文言：「水が引くまで数日〜数か月かかることがあります。2階以上か、遠くの高所へ。水や食料、薬、トイレの備えを。」伊勢湾台風の湛水期間は「数か月」と現行文にあるが出典は未確認。議長が一次情報で確認を。
- 効果：「波が引けば帰れる」を防ぐ。重さ：小。

**提案G　モーダルを「行動」「根拠」の2層に分ける**
- 画面：結果モーダル（スマホ）。上段は行動の3行（A・B・D）だけ。数値比較と出典は折りたたみ。
- 効果：下端にしかなかった重要文が最初に見える。重さ：中。

## ③やるべきでないこと
- 到達時間の「あと何分」を大きく表示すること（108分が猶予時間に読まれる）。
- 「安全」「大丈夫」「避難先」という語を、指定のない建物に使うこと。
- 推定の歩行時間や避難所の収容人数を、出典なしで出すこと。
- 緑の「安全地帯」風の塗りで、非浸水域を見せること。
