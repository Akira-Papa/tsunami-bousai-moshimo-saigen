## 確かめて問題なかった項目（まとめ）
- Esc が1枚ずつ閉じる、メモを閉じると結果へ戻りフォーカスは `r-memo`、結果を閉じるとフォーカスは `result-btn`（上記）。
- 「ほか○件を見る」を開いてフォーカスを置いたまま地名が確定しても閉じない・飛ばない。
- 通知は768・1024・390で常設の札・上の帯・深さの数字を覆わない（HUD を閉じた状態。スマホで HUD を開くと別件）。
- 地点選択の画面で横スクロールなし（4幅の全画面）。画面外へはみ出す要素なし（HUD を開いたスマホを除く）。
- 差分の目視で見つからなかったもの：`innerHTML` へのエスケープ漏れ（`h-off`・`h-rel`・`zero` は数値と固定文のみ、地名・住所・備考・避難メモは `esc()`／`textContent`）、イベントリスナーの解除漏れ（ダイアログの `keydown` は閉じるときに解除、`keyFn` は `cleanups`、`ResizeObserver` は1つ）、未定義変数（`edgeJa` の `memo.js`→`brief.js` の import に循環なし）。古い応答の混入は、`brief.update` の `token`、`onPick` の `token`、`landAround` 後の `my === token` で守られている（実測でも混入なし）。
- 差分の目視で気づいた小さな点（実測していない推測）：`tsunamiHeightAt(..., 30000)` の裏の再問い合わせは、利用者が別の地点へ移っても中断されず最大30秒走る（結果は `token` で捨てられるので害はない）。
