### 中（1件）

#### 中1　M4 の直しが効きすぎて、深い近隣セルでも「備えは少なくとも〜」と深さの説明が消える（2D と 3D で食い違う）
- 場所：src/brief.js の `officialHtml` の none 分岐（`const weak = a?.n && (a.max < 0.3 || a.edge >= 100)`）。
- 問題：「浅い」だけでなく「縁まで100m以上」でも weak になる。実測：**金城ふ頭**（プリセット。周り300m以内の最大 3.2m、約180m先）の地点選択カードは「ただし、約180m先から最大 3.2m の浸水の想定があります。これはケース01だけの値で、備えの上限ではありません。」だけで、「備えは、少なくともこの深さで」と、3.2m の深さの意味の文（2階の床を超える深さ、気象庁・内閣府の目安）が付かない。同じ地点を3Dで再現した結果の要点は「備えは、少なくとも、いちばん深い値（3.2m・公式想定・周り300m以内の最大）で考えてください」で、**同じ3.2mの扱いが2D と 3D で違う**。港区 稲永（すぐ隣・2.0m）は正しく「備えは、少なくともこの深さで」と深さの文が出る。誤りではない（「安全という意味ではありません」と値は出る）が、深い値の備えの案内が消えるのは M4 の意図（浅い・遠い1セルだけ外す）より広い。
- 直し方：`weak = a?.n && (a.max < 0.3 || (a.max < 1 && a.edge >= 100))`（遠くても1m以上なら、深さの文と「備えは少なくとも」を付ける）。live 領域（`say()`）の読み上げも同じ基準で。
