# 避難ルート（逃げる道のり）の設計　2026-11-10

本人の指示（マネージャAI経由）：
「選択した地点から、高台とかの避難できる場所へのルートもなんか出るようにしたらいいんじゃないでしょうか」
「道のデータは、国が公開してませんか？プラトーで」「行き先は、波の指定の時に、どの場所に行けば、どの高台に行けば、いいかを指定するような感じで」「浸水する道は、津波来る前の想定なんで、一旦は普通の道の案内でいいです」「道が通ってない可能性があるかもしれないのは、全部そうなんで、一旦は道は普通に案内するでいいですよ」

一次情報の確認：[09_避難ルート_一次情報の確認.md](09_避難ルート_一次情報の確認.md)（PLATEAU 標準製品仕様書・国土地理院の仕様・消防庁・気象庁を開いて確認。確認日 2026-11-10）

## 1. 結論

| 問い | 結論 |
|---|---|
| 道のデータ | **国土地理院ベクトルタイル（提供実験）の道路中心線**を、実行時に取得して使う。国のデータで、鍵・契約・課金なし、全国、ブラウザから取れる |
| PLATEAU は使えるか | **道の網としては使えない**。PLATEAU の道路モデルは、名古屋市（2022年度）では LOD1＝道路の「面」だけで、線のつながり（どの道とどの道がつながるか）を持たない。標準仕様でも、道路モデルにノードとリンクの位相は定義されていない。配信タイルを実際に開いても、すべて面だった |
| 行き先 | ①**指定緊急避難場所（津波）**（国土地理院データ・道のりの近い順に3か所）と、②**高い所**（道路の上で、標高が「海の高さ」以上になるいちばん近い地点と、「海の高さの2倍」以上になるいちばん近い地点）。**「海の高さ」（波の条件）を変えると、行き先が変わる** |
| 浸水する道・通れない可能性 | 本人の指示どおり、**避けずに、ふつうの道の案内**にする（津波が来る前に逃げる想定）。個別の道への警告は付けない。添えるのは一文だけ：「道のりは地図データからの目安です。通れるとは限りません。実際に歩いて確かめてください」 |
| 取れない・見つからないとき | 行き止まりにしない。道のデータが取れなければ、今までどおりの直線距離の一覧を出し、「道のりを取得できませんでした」と書く。道がつながらない行き先は、直線距離のまま |

## 2. 道のデータ

### 調べた候補

| 候補 | 中身 | 使えるか |
|---|---|---|
| **PLATEAU 道路モデル（tran）** | LOD0＝線（中心線）、LOD1〜3＝面。名古屋市2022は LOD1（面）のみ。位相（ノード・リンク）は標準に定義なし。CityGML一式は約2.8GB。試験運用の配信タイル（MVT）は実行時に取れるが、開くとすべてポリゴン | ×（道の網にならない。事前に中心線とグラフへ変換する別の工程が要る） |
| **国土地理院ベクトルタイル（提供実験）道路中心線** | 全国。交差点で線が分かれている（実測で、端点が別の線の途中に載る未分割のT字は0件）。道路の種類・幅・橋・トンネル・徒歩道・石段の区別あり。鍵なし・CORS可 | **○（採用）** |
| 国土交通省 歩行空間ネットワークデータ | 歩行者用のノード・リンク。名古屋市分あり（整備範囲が市内全域かは未確認） | △（全国ではない。次の課題） |
| 国土数値情報の道路（緊急輸送道路など） | 線だけで接続情報なし。非商用の表示あり | × |
| 日本デジタル道路地図（DRM）・民間の経路API | 有償・契約や鍵が要る | ×（今回は使わない。使うなら相談） |

### 使い方（実データで確かめたこと）

- タイルはズーム14を使う。道路中心線の総延長は、ズーム14・15・16で同じ（名古屋 65.2km／高知 22.8km／尾鷲 62.1km。約2.4km四方のタイル1枚ぶん）。ズーム14は1枚 約50〜110KB で、いちばん軽い。
- 使う線（コードは 2700 番台をまとめて入れる）：`ftCode` 2701（通常部）・2702（雪覆い）・2703（橋・高架）・2704（トンネル）・2711〜2714（庭園路）・2721〜2724（徒歩道）・2731〜2734（石段）。
- 使わない線：高速道路（`motorway = 1` または `rdCtg = 3`）。歩いて入れないため。
- 出典の書き方：「国土地理院ベクトルタイル提供実験の道路中心線を加工して作成」。内容が変わる可能性があること、基本測量成果ではないことは、国土地理院が明記している。
- 分かっている限界：地図にない細い道・私道・歩道橋・地下道は入っていない（石段は仕様上入るが、実測では収録が薄い）。徒歩道・石段も、ふつうの道と同じ速さで歩く目安を出している。立体交差（上を通る道と下を通る道）が、同じ点でつながって見える場合がある。徒歩道の収録は薄い（名古屋港周辺では1本）。

## 3. 行き先（波の条件から決める）

「波の条件」＝画面の **海の高さ**（海岸での津波の高さ。初期値は内閣府（2025）の市区町村別・11ケースの最大）。

| 行き先 | 選び方 | 画面での呼び方 |
|---|---|---|
| ① 指定緊急避難場所（津波） | 国土地理院のデータにある場所（直線で1km以内・近い5か所＝地図の A〜E）のうち、**道のり**が近い順に3か所 | 「指定」 |
| ② 高い所 A | 道路の上で、標高が **海の高さ以上** になる、道のりがいちばん近い地点 | 「海の高さ（○m）より高い所」 |
| ③ 高い所 B | 道路の上で、標高が **海の高さの2倍以上** になる、道のりがいちばん近い地点 | 「海の高さの2倍（○m）より高い所」 |

- 標高は、国土地理院の標高タイルから読む。10mメッシュ（全国）で候補を選び、5mメッシュ（航空レーザ測量など。ある所だけ）でもう一度確かめて、**低いほう**を使う。10mメッシュだけだと、斜面や造成地で数m高く出ることがあるため（レビューの実測：尾鷲で 19.4m に対し5mメッシュは 14.9m）。5mメッシュで基準に届かない候補は捨てる。
- なぜ「2倍」も出すか：気象庁は、津波が陸をかけ上がる高さ（遡上高）は、海岸での津波の高さの **2〜4倍に達することが多い** としている（名古屋地方気象台のページで確認）。「海の高さより標高が高ければ津波は来ない」とは言えない。だから A だけを「正解」にせず、より高い B も並べ、「さらに高い所へ」と書く。
- 探す範囲は、選んだ地点から東西南北に約1.1kmの道（ズーム14のタイル4〜6枚・最悪9枚。標高タイルも同じくらいで、実測は合わせて約0.4〜1.0MB）。その中に高い所がなければ、「この範囲の道路には、標高○m以上の所が見つかりませんでした（平らな土地です）。指定された逃げる場所の、上の階へ」と書く（名古屋港の周りはこの形になる）。
- 指定緊急避難場所のデータには、高さ・階数の情報がない（09 で確認）。場所ごとに「地面の標高」を添え、**海の高さと比べた事実だけ**を書く：低ければ「海の高さ（○m）より低い場所です。建物なら、できるだけ上の階へ」（目立つ色）、高ければ「海の高さ ○m 以上」（ふつうの色。「安全」「大丈夫」とは書かない）。建物の何階まで上がれるかは分からないので、「高台」とは呼ばない。
- 「高い所」は、その地点だけでなく、**まわり50mも基準以上**の所だけを選ぶ。川の堤防の上のような細い高まりへ案内しないため（消防庁の手引きは、海岸沿い・河川沿いの経路を避けるとしている）。

### 公的な考え方とのちがい（正直に書く）

消防庁の手引きは、避難の目標地点を「避難対象地域（津波浸水想定区域より広い範囲）の外」に定めるとしている。このサイトは市町村が決めた避難対象地域のデータを持たないので、**標高と「海の高さ」の比較で代用している**。これは市町村が決めた避難の目標地点ではない。画面にもそう書く。

## 4. 道のりの出し方

- 道の線をつないだ網の上で、**距離がいちばん短い道**を求める（ダイクストラ法。ブラウザの中で計算し、外へは何も送らない）。
- 出発点は、選んだ地点から最も近い道の上の点（150m以内。それより遠ければ「近くに道のデータがありません」）。
- 浸水する道・橋・川沿い・アンダーパスは **避けない**（本人の指示）。
- **1本の線を「正解」に見せない**：行き先は最大5つ（指定3＋高い所2）。線は行き先ごとに描き、一覧で選んだものを強調する。一覧の並びは道のりの近い順で、「おすすめの順ではありません」と書く。
- 一覧に出すもの：行き先の名前／道のり（m）／直線距離／歩く目安（1.0m/秒・実際の避難の平均0.62m/秒・歩くのが難しい人0.5m/秒）／行き先の地面の標高。
- 歩く目安は、これまで直線距離から出していたものを、**道のりから**出す（直線より長くなるので、時間も長くなる）。消防庁の「避難できる距離は最長でも500m程度が目安」は、道のりが500mを超える行き先に印を付ける。

### 最小限の一文（「誤った安心をなくす」方針との両立）

本人の指示で、個別の道に警告は付けない。代わりに、道のりの一覧の上に1か所だけ置く：

> 道のりは、地図データから求めた目安です。**通れるとは限りません**（建物の倒壊・液状化・夜や雨など）。津波が来る前に逃げる想定で、浸水する道も避けていません。実際に歩いて確かめてください。

### 02_修正方針・これまでの判断とのちがい

| これまで | 今回 | なぜ変えるか |
|---|---|---|
| 逃げる場所は直線距離だけ。歩く目安も直線から | 道のりを出し、歩く目安も道のりから | 本人の指示。直線は「川や線路をまたぐと大きく変わる」と断っていた弱点を、道のりで埋める |
| 「高台」は扱わない（指定緊急避難場所だけ） | 標高で選んだ「高い所」も出す | 本人の指示（波の条件に応じて、どの高台へ行けばよいか）。ただし「安全」とは書かず、気象庁の遡上高の説明と、より高い所を並べる |
| 前の試作では、経路は意図的に対象外だった | 出す | 本人の判断 |

直線距離の表示は、道のりが取れないときの代わりとして残す。

## 5. 画面

- **地点選択のカード**（WebGPUの有無に関係なく出る）：「津波から逃げる場所」の下に **「逃げる道のり（目安）」**。上に波の条件（海の高さ○m）、一文の注意、行き先の一覧。
- **地図**：行き先ごとの線（指定＝緑、高い所＝橙）。一覧の項目を押すと、その線を強調して地図を合わせる。
- **海の高さを変えると**、高い所 A・B の行き先と線が変わる（指定された場所は変わらない）。
- **結果の画面**（3D再現のあと）：「いちばん近い、津波の指定緊急避難場所」の1行に、道のりを添える（取れているとき）。
- 3Dの画面の中には、線を描かない（今回の範囲の外）。

## 6. 取れない・見つからないとき

| 場合 | 出し方 |
|---|---|
| 道のタイルが取れない（通信） | 「道のりを取得できませんでした（通信）。直線距離の一覧は、上に出ています」＋「もう一度」 |
| 近くに道のデータがない（150m以内に道なし） | 「近くに道のデータがありません。直線距離の一覧を使ってください」 |
| 行き先まで道がつながらない | その行き先は「道がつながりませんでした（地図にない道があるかもしれません）」。直線距離は出す |
| 標高が取れない | 高い所は出さず、「標高を取得できませんでした」。指定された場所への道のりは出す |
| 高い所が範囲にない | 「この範囲の道路には、標高○m以上の所が見つかりませんでした」 |

どの場合も、公式想定と、直線距離つきの逃げる場所の一覧は、今までどおり出る。

## 7. 完了条件

1. 名古屋（ガーデンふ頭）・名古屋以外（高知市 種崎、尾鷲など高台のある所）で、道のりの一覧と線が出る
2. 海の高さを変えると、高い所の行き先が変わる

4. 通信を切ると「取得できませんでした」と出て、直線距離の一覧は残る
5. 道のりが、実際の地図と照らして大きくおかしくない（別役が、線と距離を地図で確かめる）
6. 別役レビューで重大な指摘が0件
7. 物理の計算・3Dの水の描画には触らない

### レビュー（実装者とは別のサブエージェント2役。生の記録は `レビュー生記録/RT1_A_計算とデータ.md`・`RT1_B_安全性と表現.md`）

| 役 | 重大 | 中 | 主な指摘と対応 |
|---|---|---|---|
| 計算とデータ | 0 | 4 | 道のりは、別に書いた実装と1m以内で一致。①出発点と行き先が同じ道の区間にあると遠回りに出る→道を分けるとき元の辺を消す（直した）／②③10mメッシュだけで「高い所」を決めると、5mメッシュでは基準に届かない所がある（尾鷲・串本）→5mメッシュがあれば両方で確かめ、低いほうを使う。海の高さと±1m以内は「ほぼ同じ高さ」と書く（直した）／④気象庁の文の後半「V字谷のような地形ではさらに高く」を足し、「2倍でも、来ないという意味ではない」と書く（直した）。ほか、タイル枚数の見積りの誤り・道と標高の取得を並べて行う（直した） |
| 安全性と表現 | 0 | 9 | 屋外の場所（公園・グラウンド）と建物で、低い標高のときの文を分ける／到達までの時間と歩く時間を比べて「間に合う」と読ませない一文／「すでに」などの言い切りを消す／スマホ幅で線が欄に隠れる→地図の寄せ方を直す（すべて直した） |

直したあと、5mメッシュで確かめた結果：尾鷲の高い所は 標高 28.6m・45.1m（海の高さ17mとその2倍に対して）、串本は 36.2m・54.6m、高知は 28.9m・52.2m。

### 確かめていないこと・残っていること

- 実際に歩けるかどうか（塀・門・私有地・工事）。データは道路の中心線だけで、現地は見ていない。
- 実機のスマートフォン・Safari。
- 軽微の指摘のうち直していないもの：高い所の判定は道の頂点だけ（長い辺の途中は見ない）／壊れたタイルは黙って読み飛ばす／標高だけ取れなかったときの「もう一度」ボタンがない。
- 標高は10mメッシュと5mメッシュの低いほう。5mメッシュのない所は10mメッシュだけで、数mずれることがある（画面に書いている）。
