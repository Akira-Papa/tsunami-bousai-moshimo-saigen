### いま何が起きているか（1行）と、進み具合の帯

- 1行：「沖はまだ静かです」→「沖の海面が上がっています」→「水が防潮壁を越えました」→「陸に水が上がりました」→「ここに水が来ました（深さ○m）」→「高い水位が続いています（仮定）。ここは深さ○m」→「水が海へ戻っています」（水が残る土地では「海は下がっても、ここの水は残ります」）→「再現はここまで。実際の津波は、くり返し来ます」。
- 帯：「静か・上がる・続く（仮定）・引く」を、同じ幅の4区画で出す（帯の長さを、実際の時間と読ませないため）。時計は「再現の時計 11:15（実際の時刻ではありません）」。
- 到達の時刻（○分後）は、今までどおり出していない。

### 地点を選んだ直後のカード（スマホ幅）

最初の画面（窓の高さ456px）に、次の5つが入るようにした（直す前は、公式想定の見出しと数字の途中まで）。

1. 地名・標高
2. 公式想定（ここ○m／周り300m以内○m・備えは深いほうで）
3. 状態の1文（畳まない）：「地震から最も早くて約○分…逃げるまでの猶予の時間ではありません」。浸水セルなし・範囲外・取得失敗のときは「安全という意味ではありません」。ケース01が最大でない地域の注意も、ここに出す
4. いちばん近い【指定】の逃げる場所（道のり・歩いて約○〜○分・「通れるとは限りません」）
5. 続きの入口：「↓ ほか○件の逃げる場所・道のり・出典・ケース01の説明」

くわしい中身（公式想定の説明・逃げる場所の一覧・道のり・出典）は、今までどおり下に続く。PC幅は今までどおり。

### 3Dの動かしやすさ

| 困りごと（直す前の実測） | 直した後（`nav.mjs` の実測） |
|---|---|
| 回す・寄る中心が空中にあり、寄ると地点が画面の外へ | 中心は選んだ地点。**ホイールを200回回しても、地点は画面の同じ所**（572,406 のまま） |
| 右ドラッグで地下175m・地点から2.1kmまで行ける | 動かせるのは**地点から600mまで**（実測の最大600.0m）。地面より下へ行かない |
| 視点を切り替えている間、自分の操作が消える | **切り替え中のドラッグが効く**（切り替えは止まり、手の操作が勝つ） |
| 80°回して離すと、さらに38°滑る | 手を離して0.4秒後には止まっている（その後の動き 0.1°） |
| キーボードで動かせない | 矢印＝動かす、＋−＝寄る・離れる、Q/E＝回す、N＝北が上、0＝地点へ戻る。3Dにキーボードで入れる |
| 立って見る視点で、少し動かすと体が24m横へ動く | その場で首を振る（体の動き 0.24m） |
| いちばん引くと、空の上が黒く欠ける | 黒い画素 0%（沿岸・内陸とも） |
| 方位・戻る手段がない | 方位（押すと北が上）・◎（地点へ戻る）・PCは＋−。初めての1回だけ、動かし方の案内を出す |

画面の真ん中ではなく、**欄と操作に隠れていない所の真ん中**に地点が来るように、絵の中心を寄せた。

### 3Dの地図の見やすさ

- **名前の札**：駅・学校・病院・消防署・警察署・官公署・おもな施設・町名（国土地理院ベクトルタイル。建物を読むときのタイルから取るので、通信は増えない）。同時に PC 12・スマホ 6 まで。地点の札と【指定】の逃げる場所の札が先で、重なる名前は出さない。画面の端で切れる名前も出さない。名古屋駅の前で「名鉄名古屋駅」「近鉄名古屋駅」「中村警察署」「椿町」などが出る（重なり0）。
- **道の線**：道路の中心線を、淡いクリーム色で地面に薄く重ねる（道幅で太さを変える。乾いた地面だけ。水の上には出さない）。
- **地点の目印**：遠くからでも分かる、細い光の柱と地面の輪（近づくと消え、今までの柱と札に代わる）。
- 「表示」の中に「道・地名」の切替（既定はオン）。

## 2　見送ったこと（理由つき）

| 設計の項目 | 見送った理由 |
|---|---|
| 「海の高さ」→「津波の高さ（海岸・仮定）」への言いかえ | 応募済みの資料・動画（docs/award。今回は書き換えない決まり）が「海の高さ」で統一されている。アプリだけ変えると、資料と画面で言葉が食い違う。最初に出る所では、今も「海の高さ（海岸での津波の高さ・仮定）」と説明している |
| 「市町村で確かめてください」の重複の整理 | それぞれが、状態に結びつく注意（見つからなかった時・高い建物・道のり）として置かれている。まとめると、どれかの状態で注意が消えるおそれがある。これまでのレビューで足した文でもあるため、今回は動かしていない |
| 3Dに、逃げる道のりの帯を出す（D5・優先3） | 「水の下の区間を点線にする」表現と、その読まれ方（水の中を通れると読まれないか）の確かめに、別役の画像レビューがもう1周いる。今回は道の線と名前までとし、次の作業として提案する |
