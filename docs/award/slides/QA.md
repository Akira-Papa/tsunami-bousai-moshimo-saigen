## シリーズ全体

- 同じ背景・文字階層・主色（深い藍）・アクセント（琥珀）で統一。構図は断面・水槽・ゲージ・入れ子・分解・時系列・実画面で重複なし
- 煽りの確認：赤い警告・夜景・巨大な波・逃げる人・がれきはなし（09のがれきは修正済み）。01・11 の人影は目盛りの尺度として置いた無表情の模型
- 「予測ではありません」を 01・17・18 に明記。社会実装は 15 に「構想」、将来は 16 に「構想」と明記
- v2：PLATEAU属性の3機能は 06・16 で「実装済み」。構造は推定、建物位置の公式値は100m集約（建物ごとの公式値ではない）、避難先は自治体情報で確認、を明記
- リンク：15ページ（公開ページ・GitHub）、18ページ（同2件）にクリック可能な注釈。URLは README の値と一致
