# 04 描画とテクスチャ

対象: three.js r186（`package.json` の `"three": "^0.186.0"`）の `WebGPURenderer` と TSL で書かれた描画系。
読んだ範囲: `src/render/world.js`、`src/render/shaders.js`、`src/render/outer.js`、`src/render/markers.js`、`src/main.js` の描画ループ部分。テクスチャ・バッファの中身を確かめるため、`src/sim/swe.js` と `src/data/region.js` の関係する行も参照した。

この文書はコードから読み取れる事実だけを書く。根拠は `ファイル:行` で示す（パスは `src/` から）。three.js ライブラリ側の既定動作に頼る記述には「（three.js 既定）」と付けた。

座標の約束（`render/shaders.js:3-5`）:

- ワールド座標は x が東、y が上、z が南（単位はメートル）。
- 計算領域は `|x|,|z| < D/2`、テクスチャ座標は `uv = (xz + D/2) / D`。
- `L` は太陽へ向かう単位ベクトル。
- `env` は `(x = 領域一辺 D, y = 時刻, z = コースティクスの強さ, w = 深さ色分けモード 0/1)`。

### 1.2 `bedTex` の日照水位（A チャンネル）の焼き込み

- 太陽方向の水平成分を単位化し、1セル進むごとの太陽光線の上昇量 `rise = (l.y/hl)*dx` を求める（`render/world.js:65`）。
- 各セルから太陽側へ最大64セル歩く。`bed + bldH − st*rise` の最大値をそのセルの値にする（`render/world.js:66-73`）。水面がこの高さより低ければ影になる。
- 焼き込むのは `createWorld` の中で1回だけ（`render/world.js:77`）。`setSun()` は `uL` と影マップを更新するが、`bakeSunLevel()` は呼ばない（`render/world.js:36-43`）。
- ソースの注記（`render/world.js:56`）では A を「official depth」と書いているが、実際に入れているのは日照水位（`render/world.js:74`）。

### 1.3 テクスチャと UV の対応

- 地形の UV は `PlaneGeometry` 標準の UV を捨て、`((x+half)/L, (z+half)/L)` に書き直す。これで x が東、v が南の「領域座標」になる（`render/world.js:146-147`）。
- 航空写真・`offTex`・`bedTex`・`envTex` は、すべてこの UV で読む（`render/world.js:150-152,159`）。写真系のテクスチャは `flipY=false`（`render/world.js:51,102`）。
- `w_water` の中では UV を `(p.xz + D/2)/D` から毎回計算する（`render/shaders.js:121,137,146,192,194`）。水中で使うサンプルはすべて `textureSampleLevel(..., 0.0)`、つまりミップ0固定。
- コースティクスの光子メッシュは `PlaneGeometry(2,2)` の UV の v を反転して使う（`vec2(uv.x, 1-uv.y)`）。コメントでは「PlaneGeometry の uv.y は北向きなので、z が南の向きへ反転する」と説明している（`render/world.js:119`）。
- 外周の海マスクは UV を使わず、`positionWorld.xz` から `(xz + OL/2)/OL` を計算して読む（`render/world.js:380`）。

## 2. 各メッシュの作り方と色の決め方

### 2.1 地形（`render/world.js:138-169`）

- 形状は `PlaneGeometry(L−dx, L−dx, N−1, N−1)` を `rotateX(−π/2)` したもの。頂点は N×N 個で、各頂点の y を `region.bed[k]` にする（`render/world.js:140-143`）。法線は `computeVertexNormals()`（`render/world.js:144`）。
- 材質は `MeshStandardNodeMaterial({ roughness: 0.92, metalness: 0 })`（`render/world.js:148`）。
- 色 `colorNode` は次の順で重ねる。
  1. 航空写真 `photo`（`render/world.js:150`）
  2. 濡れ `env.x`: `mix(photo, photo*(0.55,0.52,0.47), wet*0.85)`（`render/world.js:156`）
  3. 泥膜: `mud = smoothstep(0.2,1.5, 最大水深 env.y)`。泥の色 (0.30,0.26,0.20) を `mud*0.35*wet` の割合で混ぜる（`render/world.js:155,157`）
  4. 海底: `bedI.z`（海フラグ）で (0.30,0.33,0.28) に置き換える（`render/world.js:158`）
  5. 公式想定の斜線: `off.a * uShowOfficial * 0.85`（`render/world.js:159-160`）
- 粗さ `roughnessNode` は `mix(0.92, 0.35, wet*0.8)`。濡れるほどつやが出る（`render/world.js:163`）。
- `receiveShadow=true`、`castShadow=false`（`render/world.js:165-166`）。
- 「max-depth map (after the run)」というコメントはあるが、対応する処理はない（`render/world.js:161`）。

### 2.2 スカート（領域の断面、`render/world.js:407-437`）

- 領域の4辺それぞれで、辺上の N 点について `(x, bed, z)` と `(x, −26, z)` の2頂点を作り、帯状の三角形を張る（`render/world.js:410-427`）。
- `MeshStandardNodeMaterial({ roughness: 1, side: DoubleSide })`（`render/world.js:432`）。
- 色は `positionWorld.y` で決める。上側 (0.36,0.31,0.25) から下側 (0.24,0.21,0.18) へ `smoothstep(−2,−20,y)` で移り、`0.9 + 0.05*sin(2.3y)` を掛けて地層の縞にする（`render/world.js:433-435`）。

### 2.3 計算範囲の破線（`render/world.js:389-405`）

- 外周を4セルおきに `max(bed,0)+0.8` の高さでたどる折れ線（`render/world.js:393-399`）。
- `LineDashedNodeMaterial`（白、dash 14 / gap 9、不透明度 0.55）（`render/world.js:401`）。

### 2.4 建物（`render/world.js:439-520`）

- すべての建物を1つの非インデックス `BufferGeometry` にまとめる。
- 属性は `position`、`normal`、`uv`、`binfo`(vec4) の4つ（`render/world.js:480-484`）。
- 外周リングは符号付き面積で反時計回りにそろえる（`render/world.js:447-449`）。
- 壁は辺ごとに2三角形。
  - 下端は `b.base − 1.5`（地面に少し埋める、`render/world.js:450`）。
  - UV は `u = 周長の累積(m)`、`v = 地面からの高さ(m)`（`render/world.js:460-469`）。
  - `binfo = (高さ, seed, kind, 0)`。
- 屋根は `ShapeUtils.triangulateShape` で三角形に分ける。UV は領域座標 `((x+half)/L, (z+half)/L)`、`binfo.w = 1`（`render/world.js:472-478`）。
- `seed = (id*0.6180339) % 1`。`kind` は normal=0 / solid=1 / tall=2 / shed=3 で、plateau は高さ12m超なら1、それ以外は0（`render/world.js:451-452`）。
- 材質は `MeshStandardNodeMaterial({ roughness: 0.85, side: DoubleSide })`（`render/world.js:486`）。
- 壁の色:
  - 地色: `kind<0.5`（normal）は木の色 `wood`、それ以外は `tint`。どちらも seed で色を振る（`render/world.js:493-495`）
  - 窓: 階高 3m ごと（`fy`）、横は木造 3.4m・その他 2.6m ごと（`fx`）の格子。高さ 1.2m 以上、屋根の 0.8m 下まで（`render/world.js:496-499`）。`kind>2.5`（shed）は窓なし（`render/world.js:501`）
  - 浸水の跡: 壁の外側 `dx*1.6` の所で `envTex` をサンプルし、`reached = env.w`（最大 η − 地盤）を得る（`render/world.js:504-507`）
    - `hLocal < reached` の部分は (0.45,0.40,0.33) 倍に暗くする（割合 0.85）（`render/world.js:508-509`）
    - `|hLocal − reached|` が 0.12m 以内なら泥の線 (0.22,0.18,0.13) を引く（`render/world.js:510-511`）
- 屋根の色: 航空写真を1.05倍し、灰色 0.55 を25%混ぜる（`render/world.js:512-513`）。
- 粗さは窓だけ 0.25、他は 0.8（`render/world.js:515`）。
- `castShadow`・`receiveShadow` とも true（`render/world.js:517-518`）。
- 引数 `uShowOfficial` は受け取るが、関数の中では使わない（`render/world.js:439`）。

### 2.5 防潮壁インスタンス（`render/world.js:184-204`）

- 防潮壁セルが1つ以上ある時だけ作る。`BoxGeometry(1,1,1)` を底が原点に来るよう `translate(0,0.5,0)` し、`count = leveeCount` でインスタンス描画する（`render/world.js:193-199`）。
- インスタンス番号 → `LI` → セル番号 k → `(ci, cj)` → セルの中心 `(cx, cz)`（`render/world.js:188-190`）。
- 高さの決め方: `top = S[k].x`（破堤すると地盤まで下がる標高、`sim/swe.js:390`）、`ground = LV[k].y`。
  - `positionNode` の y は `positionLocal.y * max(top−ground+0.4, 0.001) + (ground−0.4)`。
  - 水平方向の幅は `dx*1.02`（`render/world.js:196`）。
- 色は (0.62,0.61,0.58) と (0.72,0.71,0.68) を、y が 2m 周期（`fract(y*0.5)`）の半分ずつ切り替えて縞にする。混合率は 0.3（`render/world.js:197`）。
- `castShadow`・`receiveShadow` とも true（`render/world.js:201-202`）。ただし影マップは `setSun` の時しか更新されないので、破堤で壁が下がっても影マップを描き直す処理は、これらのファイルにはない（`render/world.js:31,42`）。

### 2.6 水面（`render/world.js:211-240`）

- 形状は地形と同じ `PlaneGeometry(L−dx, L−dx, N−1, N−1)`（`render/world.js:212-213`）。頂点番号をセル番号として `R`/`R2` を読む（`render/world.js:216-217`）。
- `positionNode` の y は `R.x + clamp(R2.x,0,1)*0.25`。泡のある所を 0.25m まで持ち上げる（`render/world.js:219`）。
- varying（`render/world.js:220-224`）:
  - `vWN` = 法線 `R.yz`
  - `vWH` = 水深 `R.w`
  - `vWF` = 泡 `R2.x`
  - `vWC` = 濁り `R2.y`
  - `vWU` = 流速 `R2.zw`
- 色は WGSL 関数 `w_water` の戻り値 vec4 で決める。`colorNode = out.xyz`、`opacityNode = out.w`（`render/world.js:225-232`）。
- `MeshBasicNodeMaterial({ transparent: true, depthWrite: true })`。`alphaTest 0.02`、`DoubleSide`、`renderOrder = 2`、`frustumCulled = false`（`render/world.js:218,233-237`）。
- ライトは使わない（Basic 材質）。日の当たり方と影は、シェーダーの中で `uL` と `bedTex.w` を使って計算する（`render/shaders.js:141`）。

### 2.7 飛沫（`render/world.js:243-263`）

- `SpriteNodeMaterial({ transparent: true, depthWrite: false })`。インスタンス数は `P` の要素数（131072）（`render/world.js:248,258`）。

## 3. 水面シェーダー `w_water` の処理順（`render/shaders.js:80-211`）

引数（`render/shaders.js:80-82`）:

| 引数 | 中身 |
|---|---|
| `p` | 水面のワールド位置 |
| `eye` | カメラ位置 |
| `L` | 太陽方向 |
| `nIn` | シミュレーションの法線 xz |
| `h` | 水深 |
| `turb` | 濁り |
| `foamIn` | 泡 |
| `flow` | 流速 |
| `env` | `(D, time, 集光の強さ, 深さモード)` |
| `pt/ps` | 写真 |
| `ct/cs` | コースティクス |
| `bt/bs` | `bedTex` |

### 3.1 流れマップのさざ波（`render/shaders.js:85-108`）

1. 流速 `sp = |flow|`（`:85`）。
2. 2位相の流れマップ: 周期 `T=3`s、`ph0 = fract(t/T)`、`ph1 = fract(t/T+0.5)`、重み `wgt = |ph0−0.5|*2`（`:87-90`）。
3. 振幅 `amp = 0.05 + 0.25*smoothstep(0.3,2,sp) + 0.06*smoothstep(0.1,0.6,turb)`（`:91`）。
4. 流れ方向 `fd`（流速 0.05 以下なら (1,0)）の座標系に回し、流れに沿って `stretch = mix(1, 0.25, smoothstep(0.3,2,sp))` で伸ばす（`:93-95`）。
5. 2位相それぞれの座標 `q0, q1` を流れで移流させ、fbm を中心差分（`e=0.08`）して勾配 `g0, g1` を得る（`:96-100`）。
6. 流れのない所でもうねりが出るよう、sin/cos のうねり `sw` を 0.018 倍で足す（`:102-103`）。
7. 距離による減衰: `fw = |fwidth(p.xz)|`、`far = 1/(1+2.5*fw)`。遠いほど細部を弱める（`:105-107`）。
8. 法線 `n = normalize(nIn.x − det.x, 1, nIn.y − det.y)`（`:108`）。

### 3.2 フレネル（`render/shaders.js:109-111, 72-75, 198`）

- `w_fresnel`: Schlick 近似で F0 = 0.02（`:72-75`）。
- 濁るほど `0.12 + 0.88*F` 寄りにする。混合率は `smoothstep(0.1,0.6,turb)*0.6`（`:111`）。
- 最後に、遠景のラフネス分 `0.04*rg` を足す: `Fx = min(F + 0.04*rg, 1)`（`:198`）。

### 3.3 空と建物の映り込み（レイマーチ、`render/shaders.js:114-125`）

- 反射ベクトル `R = reflect(−V, n)`。まず `w_sky(R.x, |R.y|, R.z)` を反射色にする（`:114-115`）。
- 次に反射レイを 4m 刻みで12歩（最大48m）進め、各点で `bedTex` を読む（`:119-121`）。
  - `b.y > 0.5`（建物あり）かつ `b.x + b.y > q.y`（屋上より下）なら、建物に当たったとみなす。
  - 当たったら反射色を灰色 (0.30,0.29,0.27)×(0.45 + 0.55×太陽側への向き) に置き換えて止める（`:122`）。
- `uvR` を計算しているが、使っていない（`:118`）。

### 3.4 濁りによる吸収・散乱の係数（`render/shaders.js:127-134`）

| 量 | 値 | 行 |
|---|---|---|
| 濁り `C` | `clamp(turb,0,1)` | `:128` |
| 吸収（澄んだ海） `sigSea` | (0.55, 0.32, 0.38)。コメント「伊勢湾・名古屋港の緑がかった灰色の沿岸水」 | `:129` |
| 吸収（泥水） `sigMud` | (2.4, 2.9, 3.8) | `:130` |
| 吸収 `sig` | `mix(sigSea, sigMud, smoothstep(0.08,0.7,C))` | `:131` |
| 泥のまだら `mudPatch` | `mix(0.8, 1.15, fbm(p.xz*0.012 − flow*t*0.02))` | `:132` |
| 泥の散乱 `mudScat` | (0.20,0.15,0.10) から (0.07,0.06,0.045) へ、`smoothstep(0.3,3,h)` で深さに応じて移る。× `mudPatch` | `:133` |
| 散乱 `scat` | `mix((0.04,0.07,0.05), mudScat, smoothstep(0.08,0.7,C))` | `:134` |

### 3.5 画素ごとの水深と影（`render/shaders.js:137-141`）

- 画素の位置で `bedTex` を読み、`hp = p.y − bed.x` を水深にする。コメントでは、2m 格子の段差ではなく滑らかな汀線にするためとしている（`:136-139`）。`hp` は透明度と波の先端の泡に使う。
- 影: `shadow = mix(0.25, 1.0, smoothstep(bedP.w − 0.4, bedP.w + 0.4, p.y))`。日照水位 A より下の水は 0.25 倍に暗くなる（`:141`）。

### 3.6 屈折による水底の描画（`render/shaders.js:143-150, 152-154, 164-166`）

1. 屈折: `Tr = refract(−V, n, 1/1.333)`。経路長 `tPath = h / max(−Tr.y, 0.18)`。水底での到達点 `hitXZ = p.xz + Tr.xz * min(tPath, 40)`（`:143-145`）。
2. 到達点で `bedTex` と写真を読む。反射率 `albedo = mix(photo*0.85, 海底色(0.33,0.36,0.30), bed.z) * 0.9`（`:146-150`）。
3. 太陽光の屈折 `Ls = refract(−L, 上向き, 1/1.333)`。
   - 太陽側の減衰: `down = exp(−sig*h / max(−Ls.y, 0.2))`
   - 視線側の減衰: `up = exp(−sig*tPath)`（`:152-154`）
4. 合成（`:164-166`）:
   - `bottom = albedo * exp(−4*sig.g*max(h−1,0)) * (W_SUN*2.6*L.y*down*causL*causNear*shadow + (0.35,0.42,0.5)*down*0.9)`
   - `inscatter = scat * (W_SUN*1.3*L.y*shadow + (0.30,0.38,0.46)) * (1 − up)`
   - `body = bottom*up + inscatter`
5. 段波の急な前面を透ける光: 緑 (0.10,0.20,0.14) を足す。条件は次の4つの積で、最後に ×3 と `shadow` を掛ける（`:168-169`）。
   - 逆光の度合い `pow(dot(V,−L)*0.5+0.5, 4)`
   - 斜面の急さ `smoothstep(0.05,0.25,|nIn|)`
   - 澄み具合 `1 − smoothstep(0.2,0.8,C)`

### 3.7 コースティクス（`render/shaders.js:151, 155-163`）

- **面積比法の図**: `causticRT` を到達点 `uvB` で読む（`:151`）。
- 効かせる範囲 `clearMask = (1 − smoothstep(0.15,0.35,C)) * (1 − smoothstep(1.5,4,h))`。澄んでいて水深 1.5〜4m より浅い所だけ（`:155`）。
- `causL = mix(1, caus, clearMask*env.z)`（`:156`）。
- **近景の worley 網**: コメントでは「図だけでは約1m/テクセルなので」、屈折点で画素ごとに描くとしている（`:157`）。
  - 重み `cwW = clearMask * env.z * (1 − smoothstep(0.02,0.2,fw)) * smoothstep(0.05,0.3,h)`。近く（fw が小さい）かつ水深 5cm 以上で効く（`:158`）。
  - `cwW > 0.001` の時だけ計算する（`:160`）。スケール 1.6 と 2.3 の worley を時間で逆向きに流し、それぞれ `pow(1 − worley, 4)` にして足す（`:161`）。
  - `causNear = mix(1, 0.6 + 2*cw, cwW)`（`:162`）。
- どちらも `bottom` の太陽光の項に掛ける（`:164`）。

### 3.8 太陽のきらめき（`render/shaders.js:171-172`）

- `rg = 1 − far`（遠いほど粗い）。
- `glint = W_SUN * (pow(sh, mix(1200,60,rg)) * mix(60,3,rg) + pow(sh,90)*1.2) * shadow`（`sh = max(dot(R,L),0)`）。
- 遠景では鋭い点のきらめきが、広いつやに変わる。

### 3.9 泡のレース（`render/shaders.js:175-195`）

1. 移流 worley: `fp0, fp1 = p.xz*0.9 − flow*ph*T*0.9` を `wgt` で混ぜる（さざ波と同じ2位相）。細かい fbm `fine`（スケール 3.1）も用意する（`:175-178`）。
2. フルード数 `Fr = sp / sqrt(9.81*max(h,0.02))`（`:179`）。
3. 波の先端の帯 `edgeBand = (1 − smoothstep(0,0.25,hp)) * step(0.3,sp)`（`:181`）。
4. `foamAmt = clamp(foamIn + smoothstep(0.05,0.15,slope)*smoothstep(0.8,1.2,Fr) + edgeBand*0.8, 0, 1.5)`（`:182`）。
5. レースの形: `lace = smoothstep(0.62 − 0.5*foamAmt, 0.9 − 0.4*foamAmt, cell + 0.35*fine)`。被覆率 `cover = clamp(foamAmt*1.1,0,1) * lace`（`:183-184`）。
6. 流れに沿った筋: 流れ方向に引き伸ばした fbm。`smoothstep(0.58,0.75,streak) * smoothstep(0.2,1,sp) * 0.6` と `max` を取る（`:186-187`）。
7. 建物との接触（`:189-195`）:
   - 東西南北 ±3m の4点で `bedTex.y > 0.5` を調べ、`nearB`（建物に接している）を決める。
   - 流れの前方 4m の1点で `hitB`（流れが建物に当たる）を決める。
   - `hitB*0.8*lace` を泡に加える。
8. 泡の色: (0.88,0.88,0.85)×(太陽光×`shadow` + 空の光)×`mix(0.85,1,fine)`（`:196-197`）。

### 3.10 合成・深さ色分け・透明度（`render/shaders.js:198-210`）

1. `col = mix(body, refl, Fx) + glint*Fx`（`:199`）
2. `col = mix(col, foamCol, cover)`（`:200`）
3. 建物に接する水を暗くする: `col *= mix(1, 0.6, nearB*(1−cover))`（`:201`）
4. 深さの色分け: `env.w > 0.5` かつ到達点が陸（`bed.z < 0.5`）の時、`pow(w_depthColor(h), 2.2)*1.35` と 0.9 の割合で混ぜる。`w_depthColor` は 0.3/1/2/5/10/20m の7段階（`:62-70, 204-207`）。`uEnv.w` は「深さ色分け」または「落ち着いた表示」のトグルで 1 になる（`main.js:390-391`）。
5. 透明度: `a = smoothstep(0,0.15,hp) * smoothstep(0,0.004,h)`。浅い縁ほど透け、地面が見える（`:209`）。

## 4. コースティクスの描画パス（`render/world.js:107-135, 285-292`、`render/shaders.js:214-233`）

### 4.1 光子格子

- `PlaneGeometry(2, 2, PG, PG)`、`PG = min(1024, N)`（`render/world.js:116-117`）。
- 格子の各頂点を「光子」として扱い、頂点シェーダー内で `w_causticPos` を計算する（`render/world.js:120`）。

### 4.2 `w_causticPos`（`render/shaders.js:216-233`）

1. `surfTex` を読み `s = (h, n.x, n.z, 濁り)`、ワールド座標 `x = uv*D − D/2` を求める（`:219-220`）。
2. 細かいさざ波を足す。`q = x*0.35 + 時間`（コメントでは「3m 以上の波なので 1m/テクセルの図で表せる」、`:222`）。fbm 勾配 ×0.25 と sin/cos ×0.03 で法線を乱す（`:223-226`）。
3. 平らな水面での屈折 `R0` と、乱した法線での屈折 `R` を計算する（`:227-228`）。
4. 水深 `h = max(s.x, 0)` だけ下の平らな底に投影する。
   - `flat = x + R0.xz*h/max(−R0.y,0.2)`
   - `hit = x + R.xz*h/max(−R.y,0.2)`
   - 戻り値は `vec4(flat, hit)`（`:229-232`）。

### 4.3 ラスタ化と面積比

- 頂点の位置 `vertexNode = vec4(hit.x/half, −hit.z/half, 0, 1)`。光子を**実際の到達点**に置いて描く（`render/world.js:123`）。
- `flat` と `hit` を varying `vFlat` / `vHit` で渡す（`render/world.js:121-122`）。
- フラグメントシェーダーで、画面微分から2つの面積を求める（`render/world.js:124-126`）。
  - `dA = |det(∂vFlat/∂screen)|`: 平らな水面での光束の面積
  - `dB = |det(∂vHit/∂screen)|`: 実際の到達面積
  - 比 `ratio = min(dA / max(dB, 1e−7), 25)`
- 光が集まる（dB が小さい）ほど明るくなる。`fragmentNode = vec4(vec3(ratio), 1)`（`render/world.js:127`）。
- 描画の設定: `AdditiveBlending`（折り返して重なる部分は足し合わされる）、`depthTest=false`、`depthWrite=false`、`DoubleSide`（裏返った三角形も描く）、`toneMapped=false`（`render/world.js:128-130`）。

### 4.4 描画と間引き

- `renderCaustics(force)` は `cFrame++ % 2` で1フレームおきに描き、それ以外は早期 return する。コメントは「光の網には 30Hz で十分」（`render/world.js:286-287`）。
- 描く時は、描画先を `causticRT` にして黒 (0x000000, α1) でクリアし、`OrthographicCamera(−1,1,1,−1,0,1)` で描いてから描画先を戻す（`render/world.js:112,288-291`）。このクリア色の設定は、ファイル内では元に戻していない。
- 光子格子の上限 1024（`render/world.js:116`）、RT の上限 2048²（`render/world.js:108`）。
- 起動時に `renderer.compileAsync(world.causticScene, world.causticCam)` でパイプラインを事前にコンパイルする（`main.js:311`）。

## 5. 1フレームの描画順・ライト・影・フォグ・カメラ

### 5.1 `frame()` の順序（`main.js:528-590`）

1. 経過時間 `rdt` を計算する（上限 1/20 s、`:530`）。
2. カメラのアニメーション。smoothstep 補間で 1.4s（`:532-538`）。続けて `controls.update()`（`:539`）。
3. **ニア面の調整**: `want = clamp(カメラと注視点の距離 * 0.0025, 0.3, 40)`。今のニア値と15%以上違う時だけ `camera.near` を更新し、`updateProjectionMatrix()` を呼ぶ（`:542-545`）。コメントの理由は「ニア 0.5m 固定にファー 50km では深度精度が足りず、広域の四角が z-fighting で縞になる」（`:540-541`）。
4. ピンの詳細ラベルの表示を切り替える（`:546`）。
5. 再生中ならシミュレーションを進める（`solver.step` / `outerSolver.step` / `solver.idle`、`:547-563`）。
6. `outerSolver.pack(0)` と `world.outerLayer.update()` を呼ぶ（ネスト時、`:564`）。続けて `solver.pack(再生中なら rdt、でなければ 0)`（`:565`）。ここで `R/R2/surfTex/envTex` の書き込みと飛沫の更新が行われる（`sim/swe.js:484-488`）。

### 5.2 ポストプロセス（`render/world.js:278-283`、`main.js:129-138`）

- `RenderPipeline(renderer)` を使う。`scenePass = pass(scene, camera)`、`col = scenePass.getTextureNode('output')`（`render/world.js:279-281`）。

- トーンマップ: `renderer.toneMapping = AgXToneMapping`、`toneMappingExposure = 1.05`（`main.js:135-136`）。コード上は `outputColorTransform` を変えていないので、レンダラのトーンマップと出力色空間はパイプラインの出力時にかかる（three.js 既定）。
- レンダラは `WebGPURenderer({ antialias: true })`、`shadowMap.enabled = true`、`PCFShadowMap`（`main.js:129,137-138`）。
- 起動時に `renderer.compileAsync(scene, camera)` で事前にコンパイルする（`main.js:312`）。

### 5.3 描画の順番（renderOrder）と不透明・半透明

| renderOrder | 対象 | 材質の設定 |
|---|---|---|
| −1 | 空 | 不透明、`depthWrite=false`（`render/world.js:268,271`） |
| 0（既定） | 地形・スカート・建物・防潮壁・外周地形・広域地形・ピン | 不透明（`MeshStandardNodeMaterial`） |
| 0（既定） | 外周の海 | 半透明、`depthWrite=false`（`render/world.js:381-382`） |
| 1 | 広域水面 | 半透明、`depthWrite=true`、alphaTest 0.02（`render/outer.js:68,79,82`） |
| 2 | 詳細水面 | 半透明、`depthWrite=true`、alphaTest 0.02（`render/world.js:218,233,237`） |
| 3 | 飛沫 | 半透明、`depthWrite=false`（`render/world.js:248,260`） |

three.js は不透明と半透明を別のリストで描き、それぞれの中で renderOrder を優先して並べる（three.js 既定）。

## 6. 性能上の工夫

### 6.1 シェーダー

- **ハッシュを整数化**: `w_h2` は `bitcast<vec2u>` を使う PCG 風の整数ハッシュ（`render/shaders.js:13-20`）。コメントの理由は「`fract(sin)` 系は原点から約2km で f32 の精度を失い、泡のレースやコースティクスの網が格子状にずれた」（`render/shaders.js:11-12`）。
- **日照の焼き込み**: 建物の影が水面に落ちるかどうかを毎画素レイマーチせず、CPU で1回 `bedTex.w` に焼き込み、シェーダーでは1回のサンプルで判定する（`render/world.js:63-77`、`render/shaders.js:140-141`）。
- **距離による詳細の打ち切り**: `fwidth` から出した `far` でさざ波の細部ときらめきの鋭さを弱める（`render/shaders.js:105-107,171-172`）。近景の worley コースティクスは `cwW > 0.001` の時だけ計算する（`render/shaders.js:158-160`）。
- **映り込みレイマーチは固定12歩**: 当たったら `break` する（`render/shaders.js:119-123`）。
- **広域側はコースティクスなし**: `white` テクスチャと `uEnv.z = 0` で済ませる（`render/outer.js:32-36`）。

### 6.2 テクスチャ・バッファ

- シミュレーション結果は `StorageTexture`（RGBA16F）と `R/R2` ストレージバッファに GPU 内で直接書き、描画側は `texture()` / `storage().element(vertexIndex)` で読む。CPU への読み戻しは、ピンの1セル（16バイト×2）の非同期読み出しだけ（`sim/swe.js:494-505`、`main.js:571`）。
- `bedTex`・`envTex`・`surfTex`・`causticRT` は半精度浮動小数（`render/world.js:78,109`、`sim/swe.js:126`）。
- 公式想定の斜線（`offTex`）と外周の海マスクは、起動時に Canvas へ1回だけ描く（`render/world.js:86-100`、`data/region.js:42-51`）。

### 6.3 描画の間引き

- コースティクスは1フレームおきに描く（`render/world.js:287`）。光子格子は最大 1024²、RT は最大 2048²（`render/world.js:108,116`）。
- 影マップは静的（`autoUpdate = false`、`render/world.js:31`）。
- 地形は `castShadow = false`（`render/world.js:166`）。
- ピンの目盛りラベルは 140m 以内の時だけ表示する（`main.js:546`）。
- ピンの読み出しは4フレームごと、HUD 更新は6フレームごと（`main.js:571-572`）。
- タブが非表示の間は `setAnimationLoop(null)` で描画ループを止める（`main.js:621-625`）。

### 6.4 適応解像度と計算量の自動調整（`main.js:130-133, 574-589, 613-619`）

- **基準の画素比**: `basePR = max(0.75, min(devicePixelRatio, 2, sqrt(3.6e6 / 画面画素数)))`。総画素数を約360万画素までに抑える（`main.js:130-132`）。
- **適応スケール `prScale`**: 約1秒ごとに FPS を測る。
  - 40 未満で `prScale > 0.6` なら ×0.85 に下げる。
  - 70 を超えて `prScale < 1` なら ×1.1 に上げる（上限1）。
  - 変えたら `onResize()` で `setPixelRatio(basePR()*prScale)` を反映する（`main.js:578-579,615`）。
- **1フレームあたりのサブステップ上限 `maxSteps`**: 再生中、FPS 28 未満で ×0.8（下限2）、50 超で ×1.15（上限120）にする（`main.js:580-583`）。初期値は N≥1024 で 14、N≥768 で 28、それ以外は 48（`main.js:373`）。
- 画面の短辺が 700px 未満なら、品質の初期値を格子 512 にする（`main.js:19-20`）。
