## 1. 画面遷移

### 1.1 画面の切り替え方

- 画面は `section.screen` を4つ持つ。表示中の1つにだけ `.active` が付く（`index.html:15`、`index.html:86`、`index.html:104`、`index.html:185`）。
- `.screen` は `position: fixed; inset: 0; display: none`、`.screen.active` は `display: block`（`style.css:22-23`）。
- 切り替え関数 `show(id)` は全 `.screen` に対し `id` が一致するものにだけ `active` を付ける（`main.js:17`）。
- 初期状態で `active` なのは `#pick`（`index.html:15`）。

## 2. 起動シーケンス

### 2.1 モジュール先頭

1. `qs = new URLSearchParams(location.search)`（`main.js:16`）。
2. `reduceMotion = matchMedia('(prefers-reduced-motion: reduce)').matches`（`main.js:18`）。起動時に1回だけ評価。

### 2.2 WebGPU判定（D10）

- `navigator.gpu` があり `requestAdapter()` が値を返せば `adapterOk = true`。例外は `false` 扱い（`main.js:23-24`）。

### 3.2 ピンの置き場所探索

`main.js:248-265`。

- `cellOf(x, z)`：ローカル座標 → 格子インデックス（0〜N-1 にクランプ）。

### 3.3 海の方向とマーカー

`main.js:267-282`。

- 詳細領域内で `region.sea[k]` かつ `region.dist[k] >= 25` のセルのうち、ピンに最も近いもの `seaK` を探す。
- `far = (plan.mode === 'nest')`。ネスト時は開けた海が詳細正方形の外なので、計画の方向と距離を使う：`seaX = pinX + plan.dir.x * plan.distance`、`seaZ = pinZ + plan.dir.z * plan.distance`。
- 非ネストで `seaK` が無い時は `seaX = pinX`、`seaZ = pinZ + 200`。
- `dir = normalize(seaX - pinX, seaZ - pinZ)`（`THREE.Vector2`。以降 `dir.x` が x、`dir.y` が z 成分）。
- 海マーカー `createSeaMarker(far ? -8 : seaK >= 0 ? region.bed[seaK] : -3, H)` を `(seaX, 0, seaZ)` に配置。

`main.js:284-290`。`region.buildings` のうち `height >= 5` かつ `cells >= 20` で、海マーカーに最も近い建物を `impactBuilding` とする。
