## 0. 全体像

- 入口は `createSolver(renderer, region, opts)`（`swe.js:19`）。three.js WebGPURenderer の TSL compute で全カーネルを組み立て、ホスト側の制御関数（`step` / `pack` / `requestProbe` / `readAll` / `idle` / `setPin` / `dispose` / `compileAll`）を返す（`swe.js:512-541`）。
- セル更新の本体は WGSL で書かれた `SWE_LIB`（`swe-wgsl.js:11-91`）と `SWE_CELL`（`swe-wgsl.js:94-146`）。TSL 側は `wgsl(SWE_LIB)` と `wgslFn(SWE_CELL, [lib])` で取り込む（`swe.js:136-137`）。
- 格子は $N\times N$ の正方形、セル幅 `dx`、一辺 `L`。セル番号 $k = jN + i$（`swe.js:139-142`）。ワールド座標は $x = -L/2 + (i+0.5)\,dx$、$z = -L/2 + (j+0.5)\,dx$（`swe.js:62`, `swe.js:69`）。WGSL 内の「y 方向」はワールドの z 方向（`swe-wgsl.js:93`）。
- 精度はすべて f32（`swe.js:3` のコメント: fp16 では 1 mm の乾湿判定が壊れる）。描画用テクスチャだけ HalfFloat（`swe.js:124-131`）。
- 定数: $g = 9.81$（`swe.js:16`, `swe-wgsl.js:12` `SW_G`）、飛沫粒子数 `PARTICLES = 1 << 17 = 131072`（`swe.js:17`）。

## 1. 支配方程式と離散化

### 1.1 支配方程式

保存量 $q = (h,\ hu,\ hv)$ の 2 次元非線形浅水方程式（`swe-wgsl.js:2`）。

$$
\partial_t h + \partial_x(hu) + \partial_y(hv) = 0
$$
$$
\partial_t(hu) + \partial_x\!\left(hu^2 + \tfrac12 g h^2\right) + \partial_y(huv) = -g h\,\partial_x z - \text{摩擦}
$$
$$
\partial_t(hv) + \partial_x(huv) + \partial_y\!\left(hv^2 + \tfrac12 g h^2\right) = -g h\,\partial_y z - \text{摩擦}
$$

有限体積法の 1 セル更新は `sw_cell`（`swe-wgsl.js:95-145`）で、$q + \Delta t\,L(q)$（摩擦込み）を返す。

セル状態 `q = (h, hu, hv, _)`、静的場 `s = (z, wall, manning n, _)`（`swe-wgsl.js:9`）。

### 1.2 プリミティブ変数と速度の脱特異化 ε

- `sw_vel(h, q)`（`swe-wgsl.js:22-25`）:
  $u = \dfrac{\sqrt2\, h\, q}{\sqrt{h^4 + \max(h^4,\ 10^{-12})}}$（Kurganov–Petrova 型の脱特異化。`swe-wgsl.js:8`）。
  $h^4$ の下限 $10^{-12}$ は $h \approx 10^{-3}$ m に相当し、それより十分深ければ $u = q/h$ に一致する。
- `sw_prim(q, z, ax)`（`swe-wgsl.js:28-33`）: $(h,\ \eta = h+z,\ u_n,\ u_t)$ を返す。`h = max(q.x, 0)`、速度は $h > $ `SW_HDRY` のときだけ `sw_vel`、そうでなければ 0。`ax = 0` で $(u_n,u_t) = (u,v)$、`ax = 1` で $(v,u)$。

### 1.3 MUSCL 再構成（η, h, u, v）と minmod

- `sw_minmod(a, b)`（`swe-wgsl.js:17-20`）: 符号が異なるか 0 なら 0、同符号なら絶対値の小さい方。
- `sw_rec(pm, wm, pc, pp, wp)`（`swe-wgsl.js:36-50`）: 左右隣のプリミティブ `pm`, `pp` から中心セル `pc` の 4 成分 $(h, \eta, u_n, u_t)$ それぞれに minmod 勾配 `s` を取り、$-\tfrac12$ 面と $+\tfrac12$ 面の値を作る。
  - 面値: $h^\mp = \max(h_c \mp \tfrac12 s_h, 0)$、$\eta^\mp = \eta_c \mp \tfrac12 s_\eta$、$u^\mp, v^\mp$ も同様。
  - **1 次精度への切替**（勾配 0）: 両隣のどちらかが壁（`wm > 0.5 || wp > 0.5`）、または 3 セルのいずれかで $h < 10^{-3}$（`swe-wgsl.js:38`）。
- 各方向で中心セル・東（+）隣・西（−）隣の 3 つの再構成を行う（x: `rc`, `re`, `rw` = `swe-wgsl.js:107-109`、y: `tc`, `ts`, `tn` = `swe-wgsl.js:118-120`）。そのため近傍は ±2 セル（`qe2`, `qw2`, `qs2`, `qn2`）まで参照する（`swe.js:163-174`）。
- y 方向は「−側 = 北 (j−1)」「+側 = 南 (j+1)」（`swe-wgsl.js:118`）。

### 1.4 Audusse 静水圧再構成

`sw_face(...)`（`swe-wgsl.js:77-90`）。

1. 面の左右で底面高を $z_L = \eta_L - h_L$、$z_R = \eta_R - h_R$ として復元（`swe-wgsl.js:80`）。
2. 壁の鏡像（§4.3）を適用（`swe-wgsl.js:82-83`）。
3. $z^* = \max(z_L, z_R)$、$h_L^* = \max(0,\ h_L + z_L - z^*)$、$h_R^* = \max(0,\ h_R + z_R - z^*)$（`swe-wgsl.js:84-86`）。
4. $h^*$ を使って HLL 流束を計算（`swe-wgsl.js:87`）。
5. 呼び出し側セルの圧力補正項 `fix` を返す（`swe-wgsl.js:88`）: 自セルが L 側なら $\tfrac12 g(h_L^2 - h_L^{*2})$、R 側なら $\tfrac12 g(h_R^2 - h_R^{*2})$。
6. 戻り値は `vec4(Fh, Fn, Ft, fix)`。

### 1.5 HLL 流束（Einfeldt 型波速）と接線運動量の風上化

`sw_hll(hL, uL, vL, hR, uR, vR)`（`swe-wgsl.js:52-73`）。

- 両側とも $h < 10^{-6}$ なら流束 0（`swe-wgsl.js:53`）。
- $c_{L,R} = \sqrt{g h_{L,R}}$。
- 波速:
  - 左が乾燥（$h_L < 10^{-6}$）: $s_L = u_R - 2c_R$、$s_R = u_R + c_R$（`swe-wgsl.js:57`）。
  - 右が乾燥: $s_L = u_L - c_L$、$s_R = u_L + 2c_L$（`swe-wgsl.js:58`）。
  - 両側濡れ: $u^* = \tfrac12(u_L+u_R) + c_L - c_R$、$c^* = \tfrac12(c_L+c_R) + \tfrac14(u_L-u_R)$、$s_L = \min(u_L - c_L,\ u^* - c^*)$、$s_R = \max(u_R + c_R,\ u^* + c^*)$（`swe-wgsl.js:60-63`）。
  - 補足: 先頭コメントは「Einfeldt wave speeds」（`swe-wgsl.js:6`）。実装は Roe 平均ではなく上記の $u^*, c^*$ を用いる形である。
- 物理流束 $F = (hu,\ hu^2 + \tfrac12 g h^2)$。$s_L \ge 0$ なら $F_L$、$s_R \le 0$ なら $F_R$、それ以外は標準 HLL 式 $\dfrac{s_R F_L - s_L F_R + s_L s_R (U_R - U_L)}{s_R - s_L}$（`swe-wgsl.js:65-70`）。
- **接線運動量**: $F_t = F_h \cdot (F_h > 0\ ?\ v_L : v_R)$。質量流束の向きで風上側の接線速度を運ぶ（HLLC 風の接触、`swe-wgsl.js:71-72`）。

### 1.6 セル更新式・井戸型平衡の底面勾配項

`sw_cell`（`swe-wgsl.js:95-145`）。

- 壁セル（`sc.y > 0.5`）は即 `(0, 0, 0, qc.w)` を返す（`swe-wgsl.js:103`）。
- x 方向: 東面 `FE = sw_face(rc の + 面, 東セルの − 面, …, mySide=0)`、西面 `FW = sw_face(西セルの + 面, rc の − 面, …, mySide=1)`（`swe-wgsl.js:110-111`）。y 方向の `GS`、`GN` も同じ構成（`swe-wgsl.js:121-122`）。
- **底面勾配項（井戸型平衡）**: 自セルの再構成から $z^- = \eta^- - h^-$、$z^+ = \eta^+ - h^+$ として
  $S_x = \tfrac12 g\,(h^- + h^+)\,(z^- - z^+)$（`swe-wgsl.js:113-114`）、$S_y$ も同様（`swe-wgsl.js:123-124`）。
- 更新（$k = \Delta t/\Delta x$、`swe-wgsl.js:126-129`）:
  - $h \leftarrow h - k\,[(F^E_h - F^W_h) + (G^S_h - G^N_h)]$
  - $hu \leftarrow hu - k\,[(F^E_n + \text{fix}^E - F^W_n - \text{fix}^W) + (G^S_t - G^N_t)] + k S_x$
  - $hv \leftarrow hv - k\,[(F^E_t - F^W_t) + (G^S_n + \text{fix}^S - G^N_n - \text{fix}^N)] + k S_y$
- 静水圧再構成の `fix` と $S_x, S_y$ の組で、静水（lake at rest）が保たれるように組まれている（検証は T1、§9）。

### 1.8 Manning 摩擦（半陰的）

`swe-wgsl.js:133-138`:

$$
f = 1 + \Delta t\, g\, n^2\, \frac{|\mathbf u|}{\max(h, 0.01)^{4/3}},\qquad \mathbf u \leftarrow \mathbf u / f
$$

$\mathbf u$ は更新後の $(hu, hv)$ から `sw_vel` で求めた速度。$n$ は `sc.z`。

Manning 係数の設定（`swe.js:50`）: `opts.manning` → `region.manning[k]` → 水域 0.025／陸 0.03 の順で決まる。

### 1.9 速度上限

摩擦後の速さが 15 m/s を超えたら 15 m/s に縮める（`swe-wgsl.js:141-143`）。
コメント（`swe-wgsl.js:139-140`）: $\sqrt{gh}$ に比例する薄層キャップを試したところ T2 のダムブレイク先端速度が半減したため採用しなかった。

### 1.10 時間積分: SSP-RK2（2 dispatch、A→B→A）

- `stage1`（`swe.js:177-180`）: $B = A + \Delta t\,L(A)$（`cellUpdate(A)` を B へ）。
- `stage2`（`swe.js:182-232`）: $q = \tfrac12\left(A + [B + \Delta t\,L(B)]\right)$ を作り（`swe.js:184-185`）、境界の緩和（§4）を掛け、$h \ge 0$ に切って A へ上書き（`swe.js:230-231`）。A は自セルのみ読み、近傍は B から読むため in-place 書き込みになる。
- 1 サブステップ = `stage1`, `stage2` の 2 dispatch（`swe.js:7`, `swe.js:428`）。摩擦・速度上限は各ステージの `sw_cell` 内で毎回かかる。

### 1.11 Δt の決め方（固定 Δt）

`swe.js:111-114`:

$$
h_{cap} = h_{0,\max} + 1.6H + 2,\qquad
\Delta t = \frac{0.3\,\Delta x}{15 + \sqrt{g\, h_{cap}}}
$$

- $h_{0,\max}$ は初期水深の最大値（初期値 1、`swe.js:41,55`）。
- 15 は速度上限（§1.9）。コメント（`swe.js:113`）: $|u|+|v|$ は $15\sqrt2$ に達しうるため、HLL＋静水圧再構成の正値性を保つよう CFL 係数を 0.3 とした。
- Δt は生成時に一度だけ決まり、`uPrm.x` に入る（`swe.js:117`）。実行中の適応はない。

## 4. 境界条件

### 4.1 造波帯（非ネスト時）

**重み `W.x`**（`swe.js:67-81`）。海セル（`region.sea[k]`）だけが対象。

- $e = \min(L/2 - |x|,\ L/2 - |z|)$ は正方形の縁までの距離。
- 帯の幅は $\text{relaxW} = \max(200,\ 0.04L)$ m（`swe.js:39`）。
- $\text{open} = \text{smoothstep}(40, 110, \text{dist})$。`dist` は陸までの距離で、陸から 40 m 未満の海は重み 0 になる。コメント（`swe.js:67`）: 領域外へ出る細い川が波を注入しないため。
- $w = (1 - e/\text{relaxW})^2 \cdot \text{open}$（$e < \text{relaxW}$ のとき）、それ以外は 0。
- 向き $(\text{dir}_x, \text{dir}_z) = -\nabla \text{dist} / |\nabla \text{dist}|$（中心差分、陸向き。`swe.js:73-79`）。
- `W.w` $= -z$（海の静水深、`swe.js:80`）。

**リーマン不変量による目標状態**（`swe.js:213-229`）。$d$ = `W.w`、$\eta_T$ = `uWave.x`。

- $h_c = \max(h, 0.01)$。$u_n = (hu, hv)\cdot\text{dir}/h_c$、$u_t = (hu, hv)\cdot\text{perp}/h_c$。$\text{perp} = (-\text{dir}_z, \text{dir}_x)$。
- $c_T = \sqrt{g\max(d + \eta_T, 0.1)}$、$u_T = 2\left(c_T - \sqrt{g\max(d, 0.1)}\right)$。
- 入射不変量 $R^+ = u_T + 2c_T$（目標の長波）。出射不変量 $R^- = u_n - 2\sqrt{g h_c}$（水そのものから取る）。
- $h_N = \dfrac{\max\left((R^+ - R^-)/4,\ 0\right)^2}{g}$、$u_{nN} = \tfrac12 (R^+ + R^-)$。
- 速度 $= \text{dir}\cdot u_{nN} + \text{perp}\cdot 0.8\,u_t$（接線成分は 0.8 倍）。
- 目標 $= (h_N,\ h_N\mathbf u,\ q.w)$。
- **緩和**: $q \leftarrow \text{mix}(q, \text{target}, a)$、$a = \text{clamp}(w\,\Delta t / \tau,\ 0, 1)$。$\tau$ = `uWave.z`（$L > 5000$ なら 2.5 s、それ以外 8 s）。
- コメント（`swe.js:186-188`）: 反射波は $R^-$ で自由に抜けるので、ポンプ作用やエネルギーの閉じ込めが起きない。
- `uWave.x` は `step()` 呼び出しごとに 1 回だけ設定する。値はバッチの中点時刻 $\eta_{target}(t + \text{steps}\cdot\Delta t/2)$（`swe.js:426`）。

### 4.2 縁のゴーストセル

`nb(src, qc, i, j, di, dj, inZone)`（`swe.js:148-159`）。近傍が正方形の外（$i+di \notin [0, N-1]$ など）なら、実値の代わりに**呼び出しセル自身の状態 `qc` を元にしたゴースト**を返す。`inZone` は呼び出しセルの `W.x > 0`（`swe.js:166`）。

- `inZone` が真（造波帯）: **流出のみ**。法線方向の運動量を外向きだけ残す。東側 $(di>0)$ では `max(hu, 0)`、西側では `min(hu, 0)`。z 方向も同様（`swe.js:156-157`）。
- `inZone` が偽（それ以外）: **鏡像壁**。法線運動量の符号を反転する。
- 静的場 `S` は近傍インデックスを clamp して読むので（`swe.js:143`）、ゴーストの $z$ と wall は縁セルの値になる。
- コメント（`swe.js:145-147`, `swe.js:152-154`）: ゼロ勾配コピーは流入も通すため、陸側の縁から水を送り込んでいた（名古屋港の角で 20 m の水の山）。透過縁は長い満潮保持中に縁を排水口にしていた。

### 4.3 建物（壁）の境界

- 壁セル: `bldH > 0` かつ建物種別が `'shed'` 以外（`swe.js:44`）。`S.y = 1`、初期水深は 0（`swe.js:49,53`）。
- `sw_face` で壁側の状態を鏡像にする（`swe-wgsl.js:82-83`）: $h$ と $z$ は反対側をコピーし、$u_n$ は符号反転、$u_t$ はそのまま。
- 壁の隣では MUSCL を 1 次精度にする（§1.3）。壁セル自体は更新しない（§1.6）。

### 4.4 ネスト時の縁の緩和（片方向ネスト）

`opts.nest = { solver: 外側ソルバー, offset: {x, z} }`（`swe.js:26-27`）。ネスト時は自前の造波帯を持たない（`swe.js:60`）。

**重み**（`swe.js:61-66`）: 縁から $\text{nestW} = 70$ m（`swe.js:28`）の帯で $w = (1 - e/70)^2 + 0.02$。帯の外は 0。海・陸を問わず全セルが対象。帯内は `W.x > 0` なので、縁のゴーストも流出のみ（§4.2）になる。

**外側解の双線形補間**（`swe.js:190-212`）:

- 外側格子の連続座標は $o_x = \left((i+0.5)\Delta x - L/2 + \text{off}_x + L_{out}/2\right)/\Delta x_{out} - 0.5$。$o_z$ も同様。
- $\lfloor o \rfloor$ を $[0, N_{out}-2]$ に clamp し、重み $t_x, t_z \in [0, 1]$ で外側の `A`（$h, hu, hv$）と `S.x`（$z$）を双線形補間する。
- **濡れ判定**: `W.x > 0` かつ外側補間水深 $h_o > 0.02$ m のときだけ緩和する（`swe.js:205`）。
- 目標: $h_T = \max(h_o + z_o - z_{fine}, 0)$（水位 η を共有し、細かい地形で水深を取り直す）。$u_o = hu_o/\max(h_o, 0.05)$、$v_o$ も同様。目標 $= (h_T,\ h_T u_o,\ h_T v_o,\ q.w)$（`swe.js:206-209`）。
- 緩和係数 $a = \text{clamp}(w\,\Delta t/3.0,\ 0, 1)\cdot\text{smoothstep}(0.02, 0.15, h_o)$（$\tau = 3$ s 固定。`swe.js:210`）。
- 時間補間はない。内側の各サブステップは、その時点で外側 `A` バッファに入っている状態を読む。

**`main.js` での駆動**:

- 生成（`main.js:229-236`）:
  - 外側 = `createSolver(renderer, oreg, { H, tide, breach })`、その後 `wave.hold = 3600`。
  - 内側 = `createSolver(renderer, region, { H, tide, breach, nest: { solver: outerSolver, offset: innerOffset }, calibrate: false })`、`wave.hold` は外側に合わせる。
  - 外側のピンを内側正方形の中心へ置く（`main.js:239`）。時計と波形は外側が主（`lead = outerSolver ?? solver`、`main.js:240`）。
- 毎フレームのステップ（`main.js:547-561`）:
  - 非ネスト: `steps = max(1, min(ceil(speed·rdt/dt), maxSteps))` で `solver.step(steps, calm ? 0 : 1)`。
  - ネスト:
    - `active = innerActive || outer.coast.front < L·0.75 + 600`。一度真になると保持する。
    - 予算 `budget` は、active なら $\min(\text{maxSteps}\cdot\Delta t_{in},\ \text{speed}\cdot\text{rdt})$、それ以外は $\min(\text{speed}\cdot\text{rdt},\ \text{maxSteps}\cdot 6\cdot\Delta t_{out})$。
    - 外側を `max(1, round(budget/dt_out))` ステップ進める（飛沫率 0）。
    - active なら内側を `max(0, round((t_out - t_in)/dt_in))` ステップ進めて外側の時刻へ合わせる。非 active なら `solver.idle(t_out)` で時計だけ進める（`swe.js:515`）。
  - その後、外側 `pack(0)` → 内側 `pack(再生中 ? rdt : 0)`（`main.js:564-565`）。
- `rdt` は実時間で最大 1/20 s（`main.js:530`）。
- `speed` の初期値は 20、ネスト（`far`）なら 60（`main.js:373-375`）。
- `maxSteps` の初期値は $N \ge 1024$ で 14、$N \ge 768$ で 28、それ以外 48（`main.js:373`）。1 秒ごとに fps < 28 なら ×0.8（下限 2）、fps > 50 なら ×1.15（上限 120）で調整する（`main.js:580-583`）。

## 5. 潮位・入力波形と海岸水位フィードバック制御

### 5.1 初期潮位

- `tide = opts.tide ?? 0`（T.P. m、`swe.js:23`）。
- 海セルの初期水位は $\max(\eta_0, \text{tide})$、それ以外は $\eta_0$（`swe.js:52`）。
- 初期水深は $h_0 = \max(0, \eta_{init} - z)$（壁は 0、`swe.js:53`）。
- 初期値として `T.y`（濁り）は海 0.12・他 0、`T.w` = $h_0 + z$ を入れる（`swe.js:56-57`）。

### 5.2 入力波形

`wave = { H, rise: 600, hold: 900, fall: 600, trough: 0.4, pre: 8, gain: opts.gain ?? 0.5, calibrate: opts.calibrate ?? true, tide }`（`swe.js:404-407`）。

形状 `etaTargetRaw(t)`（`swe.js:410-421`）。$s(x) = x^2(3-2x)$、$t' = t - \text{pre}$:

| 区間 | 形 |
|---|---|
| $t' \le 0$（pre） | 0 |
| $t' < \text{rise}$ | $s(t'/\text{rise})$ |
| $t' < \text{rise} + \text{hold}$ | 1 |
| $t' < \text{rise} + \text{hold} + \text{fall}$ | $1 + (-\text{trough} - 1)\, s\!\left((t' - \text{rise} - \text{hold})/\text{fall}\right)$ |
| それ以降（trough） | $-\text{trough}\cdot\left(1 - s(\min(1, t_{back}/240))\right)$。240 s かけて 0 へ戻る |

目標水位（`swe.js:409`）:

$$
\eta(t) = \text{tide} + \text{gain}\cdot(H - \text{tide})\cdot\text{shape}(t)
$$

コメント（`swe.js:405-406`）: 公式の津波高 $H$ は T.P. 基準で満潮を含むので、波は $(H - \text{tide})$ 分だけ。ランプを 600 s にしたのは、港の固有周期（約 600 s）を鋭いランプで叩かないため（`swe.js:403`）。

### 5.3 海岸水位フィードバック制御（gain の自動調整）

**集計対象の帯**（`swe.js:100-103`）: 海セルのうち $4 < \text{dist} < 60$ m で、かつ造波帯の外（`W.x = 0`）。

**集計**（`coastProbe`、`swe.js:374-383`）: 帯のうち $h > 0.01$ のセルについて:
- $\max(\eta + 100)$ を f32 ビット列の `atomicMax` で取る。
- $\text{uint}(\text{clamp}(\eta + 50, 0, 200)\times 100)$ を合計する（0.01 m 刻みの固定小数点）。
- 濡れ数を数える。

**読み戻し後の計算**（`coastUpdate`、`swe.js:442-482`）:
- `coast.now` $= \text{bits}\to\text{f32} - 100$（最大値）。`coast.max` はその累積最大。
- 平均 $\text{mean} = \text{sum}/\text{count}/100 - 50$。`coast.mean`、`coast.meanMax` を更新する。
- 最大値ビットが 0 か濡れ数が 0 なら、ここで打ち切る（`swe.js:461`）。

**制御則**（`swe.js:466-480`）:
- 条件: `calibrate` が真、$\text{shape}(t) > 0.35$、$t < \text{pre} + \text{rise} + \text{hold}$。
- 目標 $\text{want} = \text{tide} + (H - \text{tide})\,\text{shape}(t)$。
- 誤差 $\text{err} = \dfrac{\text{want} - \text{tide}}{\max(\text{mean} - \text{tide},\ 0.05)} - 1$。単一岸壁の反射ピークに引きずられないよう、**平均値**で制御する（`swe.js:468-472`）。
- $dt_s = \min(60, \max(0, t - t_{前回読み戻し}))$ は模擬時間で測る。再生倍率によらず同じ挙動にするため（`swe.js:474-475`）。
- 速度係数:
  - $\text{err} < 0$（海岸が高すぎる → 下げる）: $0.012\cdot dt_s$。
  - $\text{err} \ge 0$ かつ立ち上がり中（$t < \text{pre} + \text{rise}$）: 0。コメント（`swe.js:476`）: 海岸は伝播時間ぶん遅れるので、立ち上がり中は上げない。
  - $\text{err} \ge 0$ かつ立ち上がり後: $0.004\cdot dt_s$。
- 更新式: $\text{gain} \leftarrow \text{clamp}\left(\text{gain}\cdot\left(1 + \min(0.3, \text{rate})\cdot\text{clamp}(\text{err}, -0.6, 0.6)\right),\ 0.25,\ 1.3\right)$。

**運用上の事実**:
- 計算に使う `time` は、Promise が解決した時点のクロージャ変数の値である。読み戻しを発行した時刻ではない。
- ネストの内側は `calibrate: false`（`main.js:234`）。外側は既定の `true`。

## 6. 付随場（`aux`、`swe.js:236-305`）

`aux` は A の最新状態から、フレーム単位の模擬時間幅 $\Delta t_F$ = `uFrame.x` = `steps·dt` で計算する。

**共通量**
- 濡れ: $h > 0.005$。
- 速度: 濡れていれば $u = hu/\max(h, 0.01)$、それ以外 0。
- **半ラグランジュ移流**: 上流点 $(i - u\Delta t_F/\Delta x,\ j - v\Delta t_F/\Delta x)$ を clamp し、`Tin` を双線形補間する（`swe.js:246-253`）。

**泡**（`swe.js:257-270`）
- 生成源 $\text{src}$ は次の 4 項の和:
  - 水位上昇率 $\text{rise} = \max((\eta - \eta_{prev})/\Delta t_F, 0)$ の項 $\text{clamp}(0.35\,\text{rise}, 0, 1)$。
  - フルード数 $Fr = |\mathbf u|/\sqrt{g\max(h, 0.02)}$ の項 $0.6\,\text{smoothstep}(0.9, 2.0, Fr)$。
  - 壁衝突 $\text{imp}$ の項 $\text{smoothstep}(0.8, 3.5, \text{imp})$。$\text{imp}$ は隣接壁へ向かう速度成分 $\max(\pm u, 0)$、$\max(\pm v, 0)$ の和。
  - 浸水先端の項 $2.5\,\text{front}$。$\text{front}$ = 4 近傍に乾いた非壁セルがある × 自セルが「最初乾いていた陸」× $\text{smoothstep}(0.2, 1.5, |\mathbf u|)$。
- 減衰時定数 $\tau = \text{mix}(9, 2.5, \text{smoothstep}(0.5, 4, |\mathbf u|))$ s。
- 更新: $\text{foam} = \text{clamp}\left(\text{adv}_x e^{-\Delta t_F/\tau} + 1.4\,\text{src}\,\Delta t_F,\ 0,\ 1.5\right)$。乾燥セルは 0。

**濁り**（`swe.js:271-274`）
- $z > 0.3$ の陸上で洗掘源 $0.8\,\text{smoothstep}(0.2, 2.5, |\mathbf u|) + 0.15$ を加える。
- $\text{turb} = \text{clamp}\left((\text{adv}_y + 0.5\,\text{scour}\,\Delta t_F)\,e^{-\Delta t_F/900},\ 0, 1\right)$。
- 乾燥セルは前値 ×0.999。

**濡れ**（`swe.js:275`）: 濡れていれば 1。乾いたら $\Delta t_F/900$ ずつ減らす（900 模擬秒で 0）。

**T 出力**: $(\text{泡},\ \text{濁り},\ \text{濡れ},\ \eta = h + z)$（`swe.js:276`）。

**最大値・到達時刻**（`M`、`swe.js:278-286`）
- 濡れているとき、最大水深・最大流速・最大 η を更新する。
- 到達時刻 `M.y`: 初期値は、最初から水がある（$h_0 > 0.01$）セルが $-1$、それ以外が $10^9$（`swe.js:58`）。濡れていて `M.y > 1e8` の最初のフレームに `uFrame.y` を記録する。これはそのバッチ終了時の模擬時刻（`swe.js:432`）。
- `M.w` の初期値は $-1000$（`swe.js:59`）。

**飛沫の発生**（`swe.js:288-304`）
- エネルギー $E = \text{smoothstep}(2, 6, \text{imp}) + 0.5\,\text{smoothstep}(1.4, 2.6, Fr)\cdot\text{smoothstep}(0.6, 2.0, h)$。
- 発生条件: 濡れていて、疑似乱数 `hash(k, frameId)` $< E\cdot$ 飛沫率（`uFrame.z`）。
- 格納先: `counter` を `atomicAdd` した値 $\&\ (131072 - 1)$ のリングバッファ。
- 初期位置: セル内のランダム点、高さ $\eta + 0.1$。寿命 $0.8 + 1.2r$ s。
- 上向き速度 $\sqrt{2g\cdot\text{clamp}(0.35\,\text{imp} + 0.15|\mathbf u|,\ 0.3,\ 6)}\cdot(0.6 + 0.6r)$。
- 水平速度: 東西に壁があれば $u\times(-0.35)$、なければ $u\times 0.55$（南北も同様）に ±1 m/s の揺らぎを足す。サイズ $0.12 + 0.25r$。
- 飛沫率は `step(steps, sprayRate)` の第 2 引数。`main.js` では、ネスト外側が 0、それ以外は「静か」トグルで 0／1（`main.js:551,558-559`）。

**飛沫の運動**（`particleUpdate`、`swe.js:343-363`）
- 実時間 `uPdt` = $\min(\text{pdt}, 0.05)$ s で進める。
- 重力をかけ、抵抗 $e^{-0.35\,dt}$ を掛けて弾道運動させる。
- 消滅条件: 落下中に描画水面 `R.x` より下へ行った、または壁セルでその $z + 3$ m より下へ行った。

**描画パック**（`makePack`、`swe.js:310-339`）
- 濡れ（$h > 0.01$ かつ非壁）なら $\eta$。
- 濡れた 4 近傍を持つ乾燥・壁セルは、近傍の平均 η、描画水深 0.02。
- それ以外は $z - 0.6$、描画水深 0。
- 法線は描画水位の中心差分。

## 7. 防潮壁と越流破堤

**配置**（`swe.js:45-47`）
- `region.leveeZ[k] > 0` かつ建物壁でないセルを堤防セルとする。
- 底面 `S.x` は天端高 `leveeZ`（地盤高ではない）。堤防は「高い地形」として解かれ、壁（`S.y`）ではない。
- `LV = (1, 地盤高 bed, 天端高, 0)` を入れ、`leveeIdx` に $k$ を積む。

**破堤判定**（`breachKernel`、`swe.js:385-394`）
- 条件: 堤防セル（`LV.x > 0.5`）で、未破壊（`LV.w < 0.5`）で、その上の水深 $h > 0.05$ m。
- 処理:
  - `LV.w = 1`。
  - `S.x` を地盤高 `LV.y` に置き換える（天端高 → 地盤高への即時崩壊）。
  - `breachCount` を +1。
- `A`（水深）は書き換えない。そのため同じ $h$ のまま底面が下がる。

**実行と表示**
- `breach = opts.breach ?? true`（`swe.js:24`。コメント: 内閣府・愛知県の想定条件）。`step()` ごとに 1 回実行する（`swe.js:434`）。`main.js` からは `o.breach ?? true` を渡す（`main.js:229,233`）。
- 破堤数は `coastUpdate` で読み戻して `coast.breached` へ入れる（`swe.js:456`）。堤防が 0 件のときは読み戻さない。コメント（`swe.js:452`）: 読むとバッチ全体が reject されるため。
- `main.js` は `coast.breached > 0` で通知を出し（`main.js:451`）、結果画面に「壊れたセル」数を表示する（`main.js:505`）。

## 8. 読み戻し（ReadbackBuffer）と非同期の扱い

| 用途 | ReadbackBuffer | サイズ | 呼び出し | 頻度 |
|---|---|---|---|---|
| 海岸最大 η | `rbC` | 4 B | `coastUpdate` | `pack()` 6 回に 1 回（`swe.js:443`） |
| 浸水先端距離 | `rbF` | 4 B | 同上 | 同上 |
| 海岸合計・数 | `rbS` | 8 B | 同上 | 同上 |
| 破堤数 | `rbB` | 4 B | 同上（堤防ありのみ） | 同上 |
| 1 セルの状態 | `rbA` | 16 B（オフセット $16k$） | `requestProbe(k)` | `main.js` で 4 フレームに 1 回（`main.js:571`） |
| 1 セルの M | `rbM` | 16 B（オフセット $16k$） | 同上 | 同上 |
| M 全体 | なし | $16NN$ B | `readAll()`（`await`） | 結果画面（`main.js:474`） |

- 読み出しはすべて `renderer.getArrayBufferAsync(buffer, rb, offset, size)` で行う（`swe.js:449-453`, `swe.js:498-499`）。**待たずに** Promise を張る。
- 多重発行を防ぐフラグ: `cBusy`（海岸系）、`busy`（プローブ）。前回の Promise が `finally` で解除されるまで、次は発行しない（`swe.js:443-444`, `swe.js:495`）。
- `finally` で各 ReadbackBuffer を `release?.()` する（`swe.js:481`, `swe.js:504`）。失敗は `catch(() => {})` で握りつぶす。
- `dispose()` 後に遅れて解決した結果は、`dead` フラグで無視する（`swe.js:455`, `swe.js:521`）。
- 結果は `ArrayBuffer` でも TypedView でも読めるよう、`r.buffer ?? r` と `byteOffset ?? 0` で扱う（`swe.js:456-459`, `swe.js:502-503`）。
- 浸水先端距離: `frontProbe` が、最初乾いていた陸で $h > 0.05$ のセルについて、$|(i, j) - \text{pin}|\cdot\Delta x\cdot 10$ を uint 化して `atomicMin` する。ホスト側は $/10$ で m に戻す。`0xffffffff` のままなら `Infinity`（`swe.js:367-373`, `swe.js:460`）。ネスト時は外側のこの値で内側の起動を判定する（§4.4）。
- テスト（`tests.js:18-23`）は非同期にせず、`device.queue.onSubmittedWorkDone()` を `await` してから `getArrayBufferAsync(A)` で全体を読む。
- `dispose()`（`swe.js:520-528`）: 全カーネルの `dispose`、各バッファを `renderer._attributes` から削除、テクスチャと ReadbackBuffer を破棄する。コメントでは、1280² で約 0.3 GB のリーク防止。
