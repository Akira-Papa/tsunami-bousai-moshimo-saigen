## 1. 地点選択後の計画（`planDomain` / `findOpenSea`）

### 1.1 `findOpenSea(lat, lon, R, step, z)`（`src/data/plan.js:12-60`）

地点を中心とした ±R m の正方形を `step` m 間隔で標本化し、「開けた海」のうち地点に最も近いセルを返します。

| 手順 | 内容 | 行 |
|---|---|---|
| 標高取得 | `loadDemMosaic(bbox, z, URLS.dem10)`（10mメッシュ `dem_png`） | `plan.js:16` |
| 全滅判定 | `dem.got === 0 && dem.failed > 0` なら例外「標高タイルを取得できませんでした」 | `plan.js:17` |
| 水域判定 | `dem.sample(..., true)` が `NaN` のセル＝水（`wet = 1`） | `plan.js:19-22` |
| 地点の標高 | `here = dem.sample(lat, lon, true)`（UIの「地盤の標高 約○m（10mメッシュの目安）」に使用、`main.js:51-52`） | `plan.js:23` |
| 連結成分 | 4近傍の幅優先探索で水域を成分に分け、面積（セル数）と「探索枠の縁に接するか」を記録 | `plan.js:25-44` |
| 「開けた」条件 | 下表 | `plan.js:45-46` |
| 「広い」条件 | 陸からの距離 `dl`（4近傍・2パスのマンハッタン距離）が **150 m 以上** | `plan.js:48-54` |
| 選択 | 条件を満たすセルのうち地点からのユークリッド距離 `d = hypot(x, z)` が最小のもの | `plan.js:52-58` |
| 戻り値 | `{ best: { d, x, z } \| null, here, f }`（`f` は地点中心の局所座標系） | `plan.js:59` |

**開けた海の判定条件**（`plan.js:45-46`, `:54`）

| 条件 | 式 | 意味 |
|---|---|---|
| 面積 | `sz > minCells`、`minCells = 1e6 / step²` | 1 km² を超える水域 |
| または縁に接する小さめの水域 | `border && sz > minCells / 4` | 探索枠の縁に接し、0.25 km² を超える水域 |
| かつ幅 | `dl[k] >= 150` | 陸から 150 m 以上離れたセルだけを候補にする（運河・川を除くため、`plan.js:47` のコメント） |

**呼び出しパラメータ**

| 段 | R | step | DEMズーム | 格子 n = 2R/step | 行 |
|---|---|---|---|---|---|
| 近傍探索 | 4200 m | 20 m | z14 | 420 | `plan.js:64` |
| 遠方探索 | 16000 m | 60 m | z12 | 約533 | `plan.js:80` |

### 1.2 `planDomain(lat, lon, { baseL = 1500, maxL = 4000, maxOuter = 20000 })`（`src/data/plan.js:62-97`）

#### 分岐

| 条件 | 結果 | 行 |
|---|---|---|
| 近傍探索で `best` があり、かつ `sMin <= sMax` | **1段計算** `mode: 'single'` | `plan.js:66-77` |
| それ以外で、開けた海が見つかる（近傍の `best`、なければ遠方探索の `best`） | **ネスト計算** `mode: 'nest'`（外側の一辺 `Lo <= 20000`） | `plan.js:80-96` |
| 遠方探索でも見つからない | `{ ok: false, reason: 'no-sea' }` | `plan.js:81` |
| `Lo > maxOuter (20000)` | `{ ok: false, reason: 'far', distance }` | `plan.js:87` |

`main.js` はこの `reason` を画面の警告文に変換します（`far` → 最大20km四方にも海が入らない、`no-sea` → 周囲16km以内に開けた海なし、それ以外 → 地形データ取得失敗、`src/main.js:69-75`）。

#### 1段計算の正方形の置き方（`plan.js:66-77`）

| 量 | 式 |
|---|---|
| 海の方向 | `dir = (best.x, best.z) / best.d`（`best.d <= 1` のときは `(0, 1)` ＝ 南） |
| 一辺 L | 初期値 `baseL = 1500`。`need = best.d + 250 + 150` が L を超えれば `L = min(4000, ceil(need / 100) × 100)` |
| 中心のずらし量 s の範囲 | `sMin = best.d + 250 − L/2`、`sMax = L/2 − 150` |
| s | `s = min(sMax, max(sMin, 0.12 × L))` |
| 中心 | `center = f.toLatLon(dir.x × s, dir.z × s)`（地点から海の方向へ s） |
| 地点の局所座標 | `pointLocal = (−dir.x × s, −dir.z × s)` |

式から読める幾何：`dir` 方向に見ると正方形は地点から `[s − L/2, s + L/2]` を覆います。`s >= sMin` は「最寄りの開けた海のさらに 250 m 先まで入る」、`s <= sMax` は「地点の背後に 150 m 以上の余白を残す」ことに相当します。

戻り値：`{ ok: true, mode: 'single', L, center, distance: best.d, dir, here, pointLocal }`。

#### ネスト計算の正方形の置き方（`plan.js:80-96`）

| 量 | 式 | 備考 |
|---|---|---|
| 海の方向 | `dir = (far.x, far.z) / far.d` | |
| 定数 | `SEA = 3500`、`BACK = 1300` | 最寄りの開けた海の先に 3.5 km、地点の背後に 1.3 km の陸（`plan.js:83-84` のコメント） |
| 外側の一辺 | `Lo = max(6000, ceil((far.d + SEA + BACK) / 500) × 500)` | |
| 外側の中心のずらし量 | `s = (far.d + SEA − BACK) / 2` | |
| 外側の中心 | `outer.center = near.f.toLatLon(dir.x × s, dir.z × s)` | |
| 内側（詳細） | `L = baseL (1500)`、`center = 地点`、`pointLocal = (0, 0)` | |
| 内側の外側座標系での位置 | `outer.innerOffset = (−dir.x × s, −dir.z × s)` | |

戻り値：`{ ok: true, mode: 'nest', distance, dir, here, L, center, pointLocal, outer: { L, center, innerOffset } }`。

### 1.3 格子数 N の決定（`src/main.js:180-192`）

| 対象 | 式 | 行 |
|---|---|---|
| 詳細 | `dx0 = 1500 / N_ui`、`N = min(1280, max(N_ui, ceil(L / dx0 / 64) × 64))`（一辺が 1.5 km を超えても画質設定のセル幅を保つ） | `main.js:181-182` |
| 広域 | `N = (N >= 768) ? 1024 : 768` | `main.js:192` |
| 合成の街 | `N = (N >= 768) ? 640 : 512`、`L = 1200` | `main.js:175` |

ネスト時の詳細 `buildRegion` には `noSurroundings: true` が渡り、周辺の見た目用データは読みません（`main.js:187`）。

#### 標高PNGのデコード（`loadDemMosaic`、`tiles.js:45-88`）

| 値 `v = R × 65536 + G × 256 + B` | 標高 |
|---|---|
| `v < 2^23 (8388608)` | `v × 0.01` m |
| `v = 2^23` | データなし（`NaN` のまま） |
| `v > 2^23` | `(v − 2^24) × 0.01` m |

- モザイクは `nx × 256` × `ny × 256` の `Float32Array` で、初期値 `NaN`（`tiles.js:53-54`）。
- **404 のタイル**：`fetchOk` が `null` を返し、そのタイルは `NaN` のまま（`got` にも `failed` にも数えない、`tiles.js:58-60`）。呼び出し側ではこれが「水」になります。
- **通信失敗のタイル**：`failed++` して `NaN` のまま（`tiles.js:58`）。
- `sample(lat, lon, nearestOk)`：画素中心を `−0.5` でずらした双線形補間。モザイク外は `NaN`。4点のどれかが `NaN` のとき、`nearestOk = false` なら `NaN`、`true` なら `NaN` でない点だけの重み付き平均（重みの合計が 0.2 を超える場合のみ、それ以外は `NaN`）（`tiles.js:74-86`）。

#### 航空写真（`loadPhoto(frame, L, size, z)`、`tiles.js:91-114`）

- `size × size` の `OffscreenCanvas` を `#6d7466` で塗り、各タイルを局所座標の位置へ描画。継ぎ目を隠すため ±0.3 px 広げて描く（`tiles.js:109-110`）。
- 戻り値 `{ canvas, got, total }`。
- `size`：詳細は `N >= 1024 ? 4096 : 3072`（`main.js:187`）、周辺は 2048（`region.js:38`）、広域は 2048（`region.js:98`）。

#### ベクトルタイルの建物（`tileFeatures`、`tiles.js:149-175`）

- 面（`f.type === 3`）だけを対象にし、タイル座標で面積が正の外周リングだけ残す（穴は捨てる、`tiles.js:159-163`）。
- タイルのバッファ部分を Sutherland–Hodgman でタイル正方形に切り抜く（重複した壁を防ぐ、`clipRing`、`tiles.js:120-141`）。
- 切り抜き後の頂点が 3 未満、または面積の絶対値が 4（タイル単位²）未満なら捨てる（`tiles.js:165`）。
- 局所座標 `[x, z]` のリングと `props`（地物属性）を返す。

#### 防潮壁・護岸・水門の線（`tileLines`、`tiles.js:177-198`）

| レイヤー | `ftCode` | `kind` |
|---|---|---|
| `coastline` | 5103 | `'coast'` |
| `river` | 5203 | `'river'` |
| `structurel` | 5515 | `'gate'` |

線（`f.type === 2`）だけを対象にし、局所座標の点列 `{ kind, pts }` を返します。線はタイル境界で切り抜きません。`region.js:239` のコメントは 5103 を「coastline-at-levee」、5203 を「river-at-levee」、5515 を「gate」と説明しています。

### 2.3 PLATEAU PMTiles（`tiles.js:13`, `:117-118`, `:200-225`）

- URL：`https://shiworks.xsrv.jp/pmtiles-data/plateau/PLATEAU_2022_LOD1.pmtiles`（`PMTiles` インスタンスを1つだけ作って使い回す）。
- `loadBuildings(frame, L)`：範囲は `L/2 + 30` m、**z16** のタイルごとに次を行う（同時数 6）。
  1. `bvmap` の取得を先に開始（`tiles.js:210`）。
  2. `plateauSrc().getZxy(16, x, y)` のレイヤー `PLATEAU` から建物を取る（`src: 'plateau'`）。取得失敗は無視（`tiles.js:211-214`）。
  3. そのタイルに PLATEAU の建物が 1 件も無いときだけ、`bvmap` のレイヤー `building` を使う（`src: 'bvmap'`、`tiles.js:217`）。
  4. `bvmap` が取れたタイルでは、PLATEAU の有無に関係なく防潮壁の線を取り出す（`tiles.js:218-219`）。
- 戻り値：`{ list, lines, stats: { plateau, bvmap, tiles, failed, lineTiles } }`。
- `loadVectorCoarse(frame, L)`（広域用）：範囲は `L/2 + 50` m、**z14** の `bvmap` から、線と `building` レイヤーの全ポリゴン（`solids`）を取る。`ftCode` での絞り込みはしない（`tiles.js:227-245`）。戻り値 `{ lines, solids, tiles }`。

#### 公式浸水セルの読込（`loadOfficialCells(frame, L)`、`official.js:12-31`）

- 範囲：`half = L/2 + 60` m の正方形を緯度経度の箱 `[west, south, east, north]` に変換（`official.js:14-16`）。
- 読むタイル：manifest の `bounds` が箱と ±0.002° の余裕で重なるもの（`official.js:17`）。
- **収録範囲か（`covered`）**：タイル名 `{kx}_{ky}`（0.25° 単位のキー＝`floor(経度 × 4)`, `floor(緯度 × 4)`）が箱の範囲に 1 つでもあれば `true`（`official.js:18-22`）。

### 3.3 `finishRegion(...)`（共通、`src/data/region.js:130-267`）

#### 海と池の区別（`region.js:132-146`）

- 格子の四辺にある水セルを起点に、4近傍の幅優先探索で水セルをたどり、届いたものを `sea = 1`。
- 届かない水セル（`water = 1, sea = 0`）は池・堀として扱う。

#### 陸からの距離（`region.js:147-166`）

- 陸セル（`water = 0`）を 0、それ以外を 1e9 で初期化し、8近傍の 2パス・チャンファー距離変換（直交 `dx`、斜め `dx × √2`）。
- 陸が 1 セルも無ければ全セル 1000 m。
- `region.js:147` のコメントは「multi-source BFS」ですが、実装は 2パスのチャンファー変換です（キュー `q` に積むだけで取り出していません）。

#### 合成水深（`region.js:168-187`）

| セル | `bed`（地盤・海底 T.P. m） | `eta0`（初期水位） |
|---|---|---|
| 海（`sea = 1`） | `−min(3 + sm / 8, 14)` | 0 |
| 池（`water = 1, sea = 0`） | 下の池の処理で決める | 同左 |
| 陸 | `ground` | `ground` |

- `sm = blur(dist, N, max(2, round(30 / dx)))`：チャンファー変換の 45° の段差が水面に出ないよう、距離を先にぼかす（`region.js:169-170` のコメント）。`blur` は値を 5000 で頭打ちにしてから、分離型の箱型ぼかしを 2 回かける（`region.js:270-277`）。
- 式から、水深は岸で 3 m、陸から 88 m で上限 14 m に達します。コメントでは、以前の `1 + s/40` では港が 1〜5 m と浅く流れが減衰しすぎたと説明しています（`region.js:168-169`）。
- 海の初期水位は 0 ですが、ソルバー側で `max(eta0, tide)` に引き上げます（`src/sim/swe.js:52`）。

#### 池の扱い（`region.js:188-198`）

- 各池セルから上下左右 4 方向に距離 r = 1〜11 セルずつ広げ、最初に陸が見つかった r で、その陸の `ground` の最小値 `lo` を取る。
- 見つからなければ `lo = 0`。
- `bed = lo − 1.5`、`eta0 = lo − 0.3`（最も低い岸より 0.3 m 下に水面）。

#### 建物のラスタ化（`region.js:200-237`）

| 手順 | 内容 |
|---|---|
| 範囲外除外 | リングの外接矩形が格子外なら無視（`region.js:209`） |
| 高さ | `buildingHeight(b, bi)`（下表） |
| セル判定 | 外接矩形内の各セル中心が、リングを縮めた内側にあるか（`pointInRingShrunk`） |
| **縮小量** | `kind === 'normal'`（木造）は **0**、それ以外は **`dx × 0.25`**（`region.js:219-220`） |
| 水上の除外 | 陸セル数 0、または水セル数 > 陸セル数なら登録しない（桟橋の小屋・浮き桟橋、`region.js:230`） |
| 書き込み | 水セルは飛ばし、既存より高ければ `bldH[k] = height`、`bldId[k] = id` |
| 一覧 | `{ ring, height, base: 陸セルの ground 最小, top: 陸セルの ground 最大 + height, cx, cz（頂点平均）, src, kind, cells（陸セル数） }` |

- 木造の例外の理由（コメント）：家と家の 1〜1.5 m のすき間が 2 m 格子の水路にならないようにするため（`region.js:219`）。
- `pointInRingShrunk(r, x, z, inset)`（`region.js:304-320`）：偶奇規則の内外判定のあと、`inset > 0` なら各辺との距離が `inset` 未満のセルを除外（1セル幅の路地を残すため）。

**建物の種類**（`kindOf`、`region.js:279-282`）

| 条件 | `kind` |
|---|---|
| `src === 'plateau'` | `'plateau'` |
| `ftCode` 3101 | `'normal'` |
| `ftCode` 3102 | `'solid'` |

## 4. `region` オブジェクトの全フィールド

`finishRegion` の戻り値（`region.js:266`）に、各ビルダーがフィールドを追加します。配列はすべて長さ `N × N`、添字は `k = j × N + i`（i = 東向き、j = 南向き）。

| フィールド | 型 | 意味 | 設定箇所 |
|---|---|---|---|
| `N` | number | 一辺の格子数 | `finishRegion` |
| `L` | number | 一辺の長さ（m） | `finishRegion` |
| `dx` | number | セル幅 `L / N`（m） | `finishRegion` |
| `frame` | `{ lat0, lon0, toLocal, toLatLon }` | 中心を原点とする局所座標系 | `finishRegion`（`geo.js:9-16`） |
| `center` | `{ lat, lon }` | 格子中心の緯度経度 | `finishRegion` |
| `ground` | Float32Array | DEM の地盤高（T.P. m）。水セルは 0 | `buildRegion` / `buildOuterRegion` / `syntheticRegion` |
| `bed` | Float32Array | 計算に使う地盤・海底高（陸 = `ground`、海 = 合成水深、池 = 岸 − 1.5） | `finishRegion` |
| `eta0` | Float32Array | 初期水位（陸 = `ground`、海 = 0、池 = 岸 − 0.3） | `finishRegion` |
| `sea` | Uint8Array | 1 = 格子の縁とつながる水（海） | `finishRegion` |
| `water` | Uint8Array | 1 = DEM が無いセル（海・川・池） | 各ビルダー |
| `dist` | Float32Array | 陸からの距離（m、チャンファー変換、ぼかす前） | `finishRegion` |
| `bldH` | Float32Array | 建物の屋根の地面からの高さ（m）。0 = 空き | `finishRegion` |
| `bldId` | Int32Array | そのセルの建物の `buildings` 内の番号。−1 = なし | `finishRegion` |
| `buildings` | Array | 登録された建物 `{ ring, height, base, top, cx, cz, src, kind, cells }` | `finishRegion` |
| `seaCells` | number | 海セルの数 | `finishRegion` |
| `leveeZ` | Float32Array | 防潮壁の天端（T.P. m）。0 = なし | `finishRegion` |
| `leveeCells` | number | 防潮壁セルの数 | `finishRegion` |
| `levee` | `{ enabled, crest } \| null` | 渡された防潮壁の設定（合成の街は `null`） | `finishRegion` |
| `photo` | `{ canvas: OffscreenCanvas, got, total }` | 航空写真 | `buildRegion` / `buildOuterRegion` / `syntheticRegion` |
| `official` | `{ cells, covered, available, label?, sourceUrl?, sizeM? }` | 公式浸水セル（広域・合成は空で `available: false`） | 各ビルダー |
| `stats` | object | 詳細：`{ dem5aShare, buildings: { plateau, bvmap, tiles, failed, lineTiles }, photoTiles }`／広域：`{ outer: true, solids, lines }`／合成：`{ dem5aShare: 0, buildings: { synthetic }, photoTiles: 0, synthetic: true }` | 各ビルダー |
| `outer` | `{ L, M, hgt: Float32Array(M²), mask: OffscreenCanvas, photo } \| null` | 詳細の周辺（見た目用、`3L` 四方・192²）。`noSurroundings` や失敗時は `null`、合成の街には無い | `buildRegion` のみ |
| `manning` | Float32Array | Manning 粗度 n | `buildOuterRegion` のみ |

| # | 限界 | 根拠 |

| 1 | 水域は「DEM が無いこと」で決まる。404 のタイルに加え、**通信に失敗した個々のタイルも `NaN` のまま水として扱われる**。例外になるのは全タイルが取れない場合だけ | `tiles.js:58-60`、`region.js:59`, `:71-73`、`plan.js:17`, `:21` |
