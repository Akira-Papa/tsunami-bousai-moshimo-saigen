# 改善2周目：フィードバックと対応（2026-09-24）

- 対象：
  - 名古屋港（港区 港町）
  - 海抜ゼロメートル地帯（港区 善進本町、標高−0.2m、計算範囲2.3km四方、格子1216²）
- 証拠：修正前は `docs/review2/`、修正後は `docs/review3/`

## 汐見 凪（物理）
| # | 指摘 | 対応 |
|---|---|---|
| 1 | 2m格子の最大値と、公式の10mメッシュの値を比べている | 2mの最大値を10m単位で平均してから、100m内の最大を取る |
| 2 | 立ち上がり180秒が短く、港の固有周期（約600秒）を叩いている | 押し波・引き波とも600秒に。港の副振動の山が消えたので、制御量は岸近くの平均へ戻した |
| 3 | 計算範囲の縁が排水口になっている | 造波帯の外の縁は鏡像壁（計算範囲の外も同じように浸水しているという仮定） |
| 4 | 木造家屋のすき間が水路として開いている | 木造（普通建物）はポリゴンを縮めずにラスタ化 |

## セーブル・オコンクォ（見た目）
| # | 指摘 | 対応 |
|---|---|---|
| 1 | 俯瞰で見ると、陸の濁流が平らなペンキ | 泥の色を水深と斑で変える。遠くでは消えた凹凸を粗さに置き換え、太陽の照り返しの帯を残す。流れに沿った泡の筋。建物際の暗がりと、上流側の白い航跡 |
| 2 | 外海と計算範囲の継ぎ目が階段状 | マスクを線形補間してぼかし、外海の色を計算範囲の海と同じ式にした |
| 3 | 汀線の沖に大理石のような模様 | 引き伸ばし量を流速で変える。泡の色を一定にし、泡の部分をわずかに盛り上げる |
| 4 | 水面に建物が映らない | 反射方向へ高さマップを12回たどり、建物を映り込ませる |

## 九条 刃（GPU）
| # | 指摘 | 対応 |
|---|---|---|
| 1 | 原点から約2km離れるとハッシュの精度が落ち、泡の網目が碁盤目になる | 整数ハッシュ（PCG系）に置き換え |
| 2 | 影を1ピクセルごとに14回たどるのは重く、影の届く距離も足りない | 「日が当たる最低水位」を読み込み時に64歩ぶん計算して焼き込み、1回読むだけにした |
| 3 | Bloomのレンダーターゲット、外周テクスチャ、ReadbackBufferが解放されずに残る | すべて dispose |
| 4 | 一時停止中も飛沫が動く／表示のHzで速さが変わる | 飛沫を実時間のdtで動かし、停止中は更新しない |

## 日向 灯（わかりやすさ）
| # | 指摘 | 対応 |
|---|---|---|
| 1 | 地面の標高が画面ごとに違う（0.8m と 3.7m） | 選択画面は「10mメッシュの目安」と明記。柱を建物から避けて移したときは「約○m先に立てました」を表示 |
| 2 | 「名古屋港には1時間以上…逃げる時間はあります」が決め打ち | 公式の到達時刻からその地点の文を作る。「逃げる時間はあります」は削除し、「堤防の決壊や河川の遡上でもっと早く来ることがある」を追加 |
| 3 | ゼロメートル地帯で「水が引く」と読める | 状態表示を「水が引かない土地です（ポンプで排水するまで残ります）」に。結果には伊勢湾台風の長期湛水と、2階以上・避難ビルを追記 |
| 4 | 通知が消えない／色分けが凡例と違う色になる | 通知は8秒で閉じ、色分けONでも閉じる。深さの塗りは光を当てず、凡例と同じ色に。凡例に単位と「塗り＝この再現／斜線＝公式想定」の見本を追加 |

## 追加で見つけて直したもの（ひかり）
- プリセット「港区 南陽町」は開けた海から5.4km離れていて、計算範囲に入らなかった
  - 同じゼロメートル地帯で海に届く「善進本町」「辰巳町」に差し替えた
  - 範囲外のときも、ゼロメートル地帯の説明は表示する
- 目線の視点が建物の中に入ることがあった
  - 柱の周り16方向から、建物がなく見通しのある地面を選ぶようにした
- 俯瞰の視点で、選んだ地点が画面の外に出ることがあった
  - 地点と海岸の距離に合わせて、カメラを引く距離を決めるようにした

## 検証（修正後）
- 単体テスト3本は合格：
  - 静止湖：流速3e-5、質量誤差5.5e-10
  - ダム崩壊：中央水深0.883（理論0.889）
  - 海浜の水位上げ：汀線3.19m（入力3m）
- 善進本町：陸の浸水1.89km²
  - 水は運河をさかのぼり、線路の盛土で止まった
  - 地点には到達しなかった（公式でも、この地点のセルは浸水なし）
- 名古屋港（港町、768²、押し波開始から約23分）：
  - ここの最大2.07m（公式の100m集約では1.27m）
  - 岸近くの平均水位4.8m（入力5m）、岸壁の最大7.0m
  - 陸の浸水0.97km²
  - 公式より深めに出る。細い防潮壁・高潮防波堤を含まない仮定と、潮位・海底が合成であることが主な理由と考えられる（未検証）
