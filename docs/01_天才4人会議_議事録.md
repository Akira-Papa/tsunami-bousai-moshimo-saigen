## 論点と発言の要旨

### 1. 物理（汐見）
- 過去5作はすべて「静的な塗り分け」。**水量に上限がないため公式想定の約1.5倍に過大**という過去の失敗は、方程式を解けば構造的に消える。
- スキームは **静水圧再構成（Audusse）＋HLL（Einfeldt波速）＋水位ηで再構成するMUSCL-minmod＋SSP-RK2**。1次精度ではボアの前面が5〜8セルに鈍って「水の壁」に見えない。
- 乾湿の境界と建物隣接セルは勾配0にして1次へ自動で落とす。h<1e-4mは流束0、速度はKurganov型で脱特異化、摩擦はManningを半陰的に処理。
- 建物は**セル単位の反射壁**（多孔率モデルは10m格子以上向け）。ラスタ化はポリゴンを内側へ縮め、路地を潰さない。無壁舎は水を通す。
- 沖の造波は**水位固定（Dirichlet）禁止**。反射波の逃げ場がなく、水を注ぎ続けて過大になる。幅200mの**緩和帯**で目標状態へ緩やかに寄せる。
- 目標水位：0→Hを180秒で押し波、600秒保持、300秒で−0.4Hまで引き波。入射流速 u=η√(g/(d+η)) を岸向きに与える。
- 合成水深は d=1+s/40m（s=海岸距離、上限16m）。河川は最大3m。

### 2. 見た目（セーブル）
- 優先順位は、①法線 ②泡（ボア前面・壁への衝突・射流で発生し、移流・減衰） ③濁り（土砂濃度の移流） ④飛沫粒子 ⑤濡れと泥線 ⑥コースティクス ⑦空の反射と太陽。
- **澄んだ青い津波は最悪の嘘**。海では透明、陸に上がると茶灰色の濁流になるよう、濁りCで吸収係数を補間する。
  - 海：σa=(0.45, 0.065, 0.035)/m
  - 泥：σt=(2.4, 2.9, 3.8)/m、散乱色(0.55, 0.45, 0.30)
- コースティクスは「澄んで浅い所」だけに出す（C<0.2 かつ h<1.5m、強度×exp(−2σh)）。濁流と光の揺らぎを両立させる。
- 被写界深度は使わない（ミニチュアに見えて規模感が消える）。午後、太陽高度30°、AgXトーンマップ、弱いブルーム、大気遠近。

### 3. GPU（九条）
- 状態は `instancedArray` の f32 vec4（fp16にすると1mmの乾湿判定が壊れる）。描画用だけ HalfFloat の StorageTexture へ書き出す。
- **1サブステップ＝1ディスパッチ**。面の流束は隣のセルと重複計算になっても、帯域律速なので2パスより速い。
  - ひかりの補足：同じ関数に同じ引数を同じ順で与えるので、両側のセルでビット単位に一致し、質量保存も崩れない。
- dt は固定値にする。速度の上限（15m/s）と水深の上限から最大波速が理論上決まるため、GPU上で最大値を集計しなくてよい。
- 飛沫粒子は2^18個のリングバッファ（atomicAddでスロットを確保）、Sprite描画。
- 地点の浸水深の読み戻しは16Bだけを非同期で行い、4フレームに1回。

### 4. わかりやすさ（日向）
- 呼び名は「**もしも再現**」に統一する。「予測」「危険度」は使わない。閉じられない表示「仮定の再現・予測ではありません」を常に出す。
- 用語を2つに固定する：**海の高さ**（海岸の津波高・標高基準）／**ここの深さ**（地面からの浸水深）。形も色も別の標柱にする。
- 地点には1m刻みの目盛り柱と身長170cmの人影を立て、1階天井2.5m・2階床3mの線を引く。
- 閾値は出典が明確な3本だけ。**0.3m 避難行動が困難（内閣府）／1m 死者率が急上昇／2m 木造家屋が全面破壊（首藤1993）**。
- 公式想定（内閣府2025ケース01・100m集約）と並べて示す。公式データがない所は「未確認」、水が来なかった所は「今回の仮定では到達せず」とし、**「安全」とは書かない**。
- 最後の一言：「強い揺れを感じたら、この結果を待たずに高い所へ。」

## 決定事項

| # | 決定 | 担当視点 |
|---|---|---|
| D1 | 非線形浅水方程式：MUSCL(η)-minmod＋Audusse＋HLL＋SSP-RK2。1段＝1カーネル、2バッファ（段2は自セルだけ読むのでA上で書き戻し可） | 汐見・九条 |
| D2 | 格子は既定 768²（1.5km四方でdx≈2m）。低 512²／高 1024²。dtは速度上限15m/sと最大水深から固定で決める | 汐見・九条 |
| D3 | 建物＝反射壁。PLATEAU LOD1の実測高さを優先し、なければ地理院ベクトルの建物種別から推定する。無壁舎は水を通す | 汐見 |
| D4 | 沖側に幅200mの緩和帯。押し波180秒→保持600秒→引き波300秒 | 汐見 |
| D5 | 付随場：泡F・濁りC（移流）、最大浸水深、到達時刻、濡れ | セーブル・九条 |
| D6 | 水面は解析的な屈折（水底を航空写真＋コースティクスで描く）、フレネル、空と太陽、泡の合成、濁りによる吸収の補間 | セーブル |
| D7 | 飛沫GPU粒子（壁への衝突・射流）、濡れた地面、建物の泥線 | セーブル・九条 |
| D8 | 地点の目盛り柱・人影・階の線、HUDは4数値（いまの深さ・最大・流速・到達）、公式想定と並記 | 日向 |
| D9 | 「もしも再現」「海の高さ／ここの深さ」の用語、「安全」とは書かない、避難の一言 | 日向 |
| D10 | 非WebGPU端末では明示して案内する。控えめ表示と reduced motion を尊重 | 日向・九条 |
