# 津波シティ WebGPU — 叩き台（会議前・ひかり作成）

## 依頼（あきらパパ様・2026-09-24）
- 過去の津波3Dサイトの経緯を理解したうえで、全く新しい天才4人の会議を経て作る
- 地図で地点を選ぶ → その場所の街中で、津波高まで「液体」として水が押し寄せるシミュレーション
- three.js WebGPURenderer＋TSLコンピュート。Houdini並みの水表現（コースティクス含む）
- 建物とのぶつかり・津波のリアルな動きを物理計算する
- 改善→フィードバック→改善を2周

## 過去資産の要約（何が違うのか）
| 過去 | 方式 | 限界 |
|---|---|---|
| nagoya-bousai-1 | MapLibre＋公式ラスタ重ね | 物理なし・浸水は公式画像任せ |
| nagoya-tsunami-lecture | SVG教材 | 架空地形 |
| nagoya-fable5 A/1/2 | Cesium平面水面／color-relief／BFS | 静的水位。水量上限なしで公式の1.5倍に過大 |
| nankai-japan A/1 | 全国版Cesium／MapLibre | 海岸最大値を内陸へ一律適用（過大・過小） |
| nankai-precomputed | 内閣府2025の10mメッシュを100m集約＋ETOPO浅水方程式(0.1°) | 沿岸は静的BFS。街路スケールの流体ではない |
| houdini-water-webgpu | WebGPU水面＋面積比コースティクス | プールの波。津波・建物・地形なし |

→ **今回の新規性：街路スケール（1〜2m格子）の非線形浅水方程式をGPUで解き、建物を固体壁として水がぶつかり・回り込み・跳ね返る様子を、実地形と実建物で見せる。**

## 使えるデータ（確認済み・CORS可）
- 標高：地理院 `dem5a_png` z15（5m LiDAR）＋ `dem_png` z14（10m）補完。x=R·65536+G·256+B、2^23=無効（海・水面）
- 建物：地理院 `experimental_bvmap` z16 `building` レイヤー（ポリゴン、ftCode 3101普通/3102堅ろう/3103高層/3111無壁舎）。PLATEAU LOD1 PMTiles（123都市、実測高さ）も候補
- 航空写真：地理院 `seamlessphoto` z17（地面テクスチャ）
- 津波高：内閣府2025 市区町村別の海岸最大津波高 413行（`public/data/tsunami_h.json`）
- 市区町村代表点：1,747件（`public/data/municipalities.json`）
- 公式浸水深：内閣府2025 ケース01 を100m集約（最大浸水深・最早到達秒）（`public/inundation/1/100/`）

## 叩き台アーキテクチャ
1. 地点選択：MapLibre（地理院淡色）で市区町村検索／地図クリック。その市区町村の公式最大津波高を初期値に
2. 領域構築：地点を含み海岸を含む約1.5km四方。DEM→地盤、無効値→海（海岸距離で合成水深）、建物ポリゴン→ラスタ化（高さ付き）
3. 物理：非線形浅水方程式（有限体積・静水圧再構成・HLL流束・Manning摩擦・wet/dry）。建物セルは反射壁。沖側に造波緩和帯（目標水位 η(t) を津波高Hまで上昇→保持→引き波）
4. 付随場：濁り（土砂）・泡（ボア前面・建物衝突）・最大浸水深履歴・濡れ
5. 表現：水面メッシュ（高さ場）＋フレネル反射・屈折・吸収、面積比コースティクス、泡、飛沫パーティクル（GPU）、濡れた地面
6. 地点計測：選んだ地点にスケール柱と人の大きさ。現在浸水深・最大・流速・到達時刻、公式想定との比較
7. フォールバック：通信失敗時は合成の街で動作
